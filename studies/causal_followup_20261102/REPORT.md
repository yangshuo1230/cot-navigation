# 首次展开、stack长度与分隔符计数：进一步因果复查

2026-11-02；同一冻结185k In Context DFS-state模型；CPU FP32。复用已有18条N100 test参考查询。首次展开有13条满足选择条件；stack和bar干预覆盖全部6条long test。不是新自由生成成功率。

## 一、第一次PUSH到新节点时，后继与已访问信息怎样形成候选

选择当前节点u第一次成为栈顶、并有一个后继v已从其他分支访问过的状态。之前没有u的PUSH或展开记录，因此不能用“u上次候选列表删去上次选择”解释。18条中13条可用，其余5条显式保留为不可用。

### 配对任务，而不只是在非法历史中擦除字段

为每个状态选择与v同拓扑层、未访问、不是u的后继且不是查询起终点的w。对图和历史中的v/w进行一致的节点交换，但保留u的原始出边。因为u之前未展开，旧历史仍可合法执行；当前u的后继集合不变，已访问的节点从v改成w，正确候选应新增v。

独立replay不只检查此前记录，还给当前状态补上正确候选及对应PUSH，**13/13通过至当前记录的合法性检查**。这是合法的候选前缀配对任务，未声称两条完整后续自由搜索都成功。

| 条件 | 整个候选集合符合该条件预期 | 原先被排除的v重新出现 |
| --- | ---: | ---: |
| 原基线 | 13/13 | 0/13 |
| 仅当前visited把v改成w | 0/13 | 0/13 |
| 合法配对：图与访问历史一致改写，u的后继不变 | 11/13 | 12/13 |
| 配对历史，但把当前显式visited恢复为原版 | 11/13 | 12/13 |
| 只改配对图，保留原历史与当前visited | 13/13 | 0/13 |
| 把u→v改成u→未访问w | 13/13 | 输出新增w，13/13 |

“当前visited恢复原版”的条件刻意与配对历史不一致，用于检验显式列表是否覆盖历史信号。图控制和合法任务配对共同支持：**第一次展开确实结合当前出边与历史访问信号，但当前打印出来的visited不是决定过滤的主要直接输入。** 12/13重新输出v不等于12/13整个集合正确，必须保留11/13这个完整判据。

### 历史信号的来源缩小到了“曾被选中的候选/PUSH事件”

保持图和当前状态原样，只把历史中v在指定角色的出现改成w。这类角色编辑可能破坏旧历史一致性，不当作合法任务，只作定位诊断。

| 改写历史角色 | v重新出现 | 新候选集合完整正确 |
| --- | ---: | ---: |
| 历史visited | 0/13 | 0/13 |
| 历史stack | 0/13 | 0/13 |
| PUSH参数 | 0/13 | 0/13 |
| stack与PUSH参数 | 0/13 | 0/13 |
| 所有candidate中的v | 10/13 | 9/13 |
| **当时确实被PUSH选中的candidate位置** | **10/13** | **9/13** |
| 从未在当时被选中的candidate位置 | 0/13 | 0/13 |
| **选中candidate与相应PUSH参数** | **12/13** | **11/13** |
| 未选中candidate与PUSH参数 | 0/13 | 0/13 |
| 全部历史角色 | 12/13 | 11/13 |

在合法协议里PUSH选择当前候选列表第一项，故“选中candidate”指该记录列表第一项，且其PUSH参数为v；并非泛指曾在候选列表出现过。结果不支持简单的“只要历史提过v，就判已访问”。它支持更具体的历史选择见证：旧的选中候选及PUSH参数共同提供了某节点已被探索的信息。

目前可画的功能关系是：

```text
图中当前u的出边 ───────────→ 可选邻居提议
此前实际选中过的候选/PUSH事件 → 隐式访问线索 → 抑制已探索邻居
当前显式visited列表 ───────── 这些编辑中未起决定作用
```

这仍没有解码历史选择见证如何在各层、多跳进入当前query/状态表示，也没有证明具体的集合差运算。更不能把“旧参数位置的上下文表示有功能”简化为“只读参数字面节点”；前一轮只改参数字面节点无效，本轮也复现了这一点。

## 二、stack：从L2开始逐层因果干预

使用上一轮仅在val拟合的长度probe，各层独立构造方向，使目标长度解码值增减、已输出数量解码值不变。6条long查询各选中段一个stack末节点和倒数第二节点，共12个接收位置。末节点增加目标长度应继续，倒数第二节点减少目标长度应提前停止。

L2、L3、L4、L5、L6分别测试1、2、4单位三档，配相同范数、对长度与进度probe均为零的随机方向及sham，共420条件。

**所有层、所有剂量，停止/继续切换均为0/12，随机对照也为0/12。** 各层最大剂量约占残差范数的3.0%–11.0%；不是只在L4做了一次小干预。解码长度确实按设定改变，已输出数量解码值不变，接收位置之前logits精确不变。

### 自然表示交换：验证是否存在可被操纵的停止信息

同一条query内选两个位置，当前token都为起点s，都刚输出第一个stack节点，即已输出数量j=1；但一条记录目标stack长度为1，应输出`|`，另一条长度大于1，应继续。替换的是选定接收位置的表示，其他位置保持原状。供体可能来自该轨迹更晚位置，这是离线反事实，不是合法生成时可提前获得的信息。

| 层 | 完整自然供体交换 | 只换probe长度分量 | 去掉长度/进度线性分量后的供体差异 | 同范数probe-null随机方向 |
| --- | ---: | ---: | ---: | ---: |
| L2 | 7/12 | 0/12 | 7/12 | 1/12 |
| L3 | 7/12 | 0/12 | 7/12 | 1/12 |
| L4 | 10/12 | 0/12 | 9/12 | 1/12 |
| L5 | 12/12 | 0/12 | 12/12 | 2/12 |
| L6 | 12/12 | 0/12 | 12/12 | 0/12 |

结果说明：停止/继续信息在中高层确实可以被因果操纵；但**上一轮高R²的线性长度/进度子空间，不是已确认的停止控制器**。从供体差异中剔除这两个probe方向，仍可在L5/L6使12/12切换，尽管probe解码值保持原样。

这也不是“证明长度没有被使用”。完整供体差异还含后续节点内容、状态阶段及其他信息；nullspace交换可能离开自然表示流形。真实控制仍可能依赖非线性、分布式或位置比较。当前应停止把线性长度probe的可读性当成计数器机制证据。

## 三、`|`的L1是否数前面的`|`来确认字段身份

明确测试一种简单模型：当前字段由此前bar数量模3确定；增加1/2个bar应相应旋转字段，增加3个应回原身份。此前所有同字面`|`的L1 V完全相同，这不禁止用attention总量与位置估计数量，但其直接贡献是加权质量乘以同一个V，不是未归一化的整数计数。

### 计数probe

复用4491个bar位置，query-disjoint的val拟合/test评估，目标为此前bar的总个数。L1读数R²=0.944，但RMSE为13.28个、四舍五入精确数对率仅2.9%；把读数取模3预测字段仅33.1%，接近随机。单用位置/前一bar距离/log位置的控制R²更高，为0.987。

因此能读出粗略累计进度，但不能据此说发现了精确的模3计数器。线性probe失败也不排除非线性计数码。

### 控制数量、位置与语法的因果实验

6条long query×三种bar=18个接收位置。主要实验只在当前位置的L1 attention行中，将指定key的K/V改为bar或普通节点对应的K/V，保留实际输入、绝对位置、其他位置隐藏状态、原Q不变，重算该行。如此可改变L1“看到的bar数量”，不破坏整段实际输入的语法。使用同一套val训练的字段身份probe，检查L1–L6接收表示。

- 当前stack内增加1、2、3个虚拟bar；另在远处旧记录中增加/减少1、2、3个。
- 远处修改保持最近一个bar的距离不变。
- 等数量迁移：远处移除k个、近处增加k个，bar总数不变，只改变距离分布。
- 另做真实输入的近处替换与普通节点身份替换对照。真实bar替换可能破坏语法，单独解释。

共324条件。主要结果：

| 条件，每种18位置 | L1身份probe改变 | L2/L4身份probe改变 | 最终下一token改变 |
| --- | ---: | ---: | ---: |
| 近处虚拟增加1 | 4/18 | 0/18、0/18 | 0/18 |
| 近处虚拟增加2 | 8/18 | 0/18、0/18 | 0/18 |
| 近处虚拟增加3 | 9/18 | 0/18、0/18 | 0/18 |
| 远处虚拟加/减1、2、3 | 每种0/18 | 每种0/18、0/18 | 每种0/18 |
| 数量不变、迁移1 | 4/18 | 0/18、0/18 | 0/18 |
| 数量不变、迁移3 | 9/18 | 0/18、0/18 | 0/18 |
| 真实输入增加1/2/3 | 4/8/9个 | L2为0/4/4个；L4均0 | 3/5/7个 |

近处虚拟增加bar和保持数量的迁移，造成相同数量的L1 probe变化，说明不能把L1变化直接解释成数量编码。增加1或2后，L2/L4均没有按预期旋转字段；加3后保持身份不能单独作为周期性证据，因为1、2时也保持。真实输入破坏会改变部分最终输出，但没有出现清晰的“1/2旋转、3恢复”模式，L4字段解码仍稳定。

**未支持“当前接收位置L1单独数前文bar，再直接决定字段身份”这一简单机制。** 这不排除在别的位置累计、在更多层重新整合、只统计某个特定窗口或非线性/冗余计数。虚拟实验仅改一行，后续仍可从未改变的历史状态纠正；这既是避免语法破坏的优点，也是不能证明不存在分布式计数的边界。

## 证据范围与文件

![因果汇总](causal_summary.png)

`fresh_candidates.py`含221个候选生成条件，13条query；`verify_pairs.py`独立检查13组配对状态的合法性。`length_layers.py`含420条件，`length_donor.py`含300条件，均为6条query上的L2–L6反事实。`bar_count.py`含324条件；`count_probe.py`为累计bar数量的query分离probe。`summary.json`保留各条件计数，`validation.json`检查probe方向、sham、历史logits不变、距离控制及完整性。实验条件不是独立query，所有失败和不可用查询均保留。

这些是同一模型、已有参考查询的探索性研究；没有新增自由搜索成功率结论，没有训练原模型。首次展开的历史选择见证结果尚不是完整逐层电路；stack和bar计数的阴性结果不等于排除了所有长度/计数实现。
