# Cursor FFN-role 结论复核

核对对象：服务器 `research/ffn_role_20261023/study.py`、`simple.json`、`hard.json`。代码 SHA256：`3e0890ff37e6dcbc265c9c177fb52628d1d3fcff77c0a61eedfcaf29c8130e48`。未修改原实验；新的审计只用 CPU 冻结推理、数值拟合，没有训练或改动主模型。

结论：基本测量可复现，但“后继表在 FFN、祖先表只在 embedding、YES/NO 走祖先一路”的机制分解尚未被证明。祖先相关线性结构得到支持，后继的原生提取依赖训练后的 FFN/embedding/head 组合也得到支持；存储位置的排他性、因果中介和唯一汇合层不成立为已证结论。

## 重新执行的基本测量

使用原模型 forward 加 FFN hook，而不是原实验重写的 forward；重新拟合其仿射 FFN，并用原模型 hook 替换。这一组值独立复现：

| YES/NO 限定 balanced accuracy | 简单 | 困难 |
|---|---:|---:|
| 原模型 | 0.931 | 0.976 |
| 去掉所有层起点 FFN | 0.824 | 0.777 |
| 去掉所有层终点 FFN | 0.487 | 0.699 |
| 去掉所有层分隔符 FFN | 0.895 | 0.920 |
| 全部 FFN 换成拟合的仿射映射 | 0.926 | 0.955 |

数值复现不自动验证对其机制的解释。

## 1. 无法由新解码器失败排除 embedding 中的后继信息

60 个训练焦点节点上拟合的线性、kNN、MLP 读出不能精确推广到其他焦点节点，说明这些方法尚未找到强可推广的后继解码规律。不能推出不存在更复杂、依赖不同基底或与原网络协同的编码。13%–19% 的新解码器 recall 还明显高于约2%的全节点随机水平，因此“embedding 只是地址、完全不含后继几何”过强。

随机化 FFN 后原头读不出，说明原解码路径需要训练过的 FFN，不区分 FFN 存储事实与 FFN 解码 embedding。置换输入 embedding 而不改输出头后，结果跟向量走是该架构的预期性质：没有额外 token-ID 信道，函数收到相同向量自然给出相同结果。这项是有效 sanity check，但不是知识定位证据。

## 2. 线性映射也能存地址查找表

实测两张图的节点 embedding 矩阵均为 100×128、行秩100。因而任意给这100个地址指定100×128输出，均存在仿射映射精确实现。审计用随机输出表验证，重建 RMS 约 1e-14。这个验证使用全部节点，不是留出泛化测试；用途是反驳“线性就不可能是查表”。

查询仿射替换拟合的是原 FFN 输出，且训练查询覆盖已知节点身份。它是对训练过的图模型做分布内蒸馏，映射参数可以继承节点关联；不能据此将事实全部归给输入 embedding。attention softmax 和 LayerNorm 仍有非线性，也不能将整个关系计算称为线性。

附加控制：在同一批原生查询 FFN 输入上，把拟合目标换成随机初始化的同尺寸 FFN 输出，仿射重建验证 R² 仍为简单0.987–0.996、困难0.982–0.991。随机 FFN 使用初始化 std=.02，不是匹配训练后权重范数的控制；它仅说明高重建 R² 本身不特异地指向图知识的位置。

## 3. 所谓“正交剩余”不是严格概念正交子空间

代码 `residualize`（study.py:285）返回 ridge 预测误差 `target-prediction`，而不是 residual 特征空间的正交投影。ridge 正则下训练误差也不严格与输入正交；留出样本更无此保证。`crossfit_parts`（study.py:335）用同一批训练节点的 in-sample 误差训练第二个 probe，再去评估 out-of-sample 误差，有明显尺度差异。

seed17 第一折、FFN1：训练/测试误差 RMS 简单为0.685/7.092，困难为0.918/5.802，约相差10.3倍/6.3倍。故剩余 probe 失败可以来自尺度/分布偏移、有限样本或读出选择，不能推出“FFN 没有额外祖先信息”。应使用嵌套 cross-fitting 生成第二阶段的训练误差，或严格定义并检验特征子空间投影；即使修正后阴性，也不能证明所有非线性信息不存在。

## 4. 祖先 probe 有信号，但指标需要修订

原 `crossfit_probe`（study.py:315）将五个不同解码器的 OOF 分数合并，再对每个候选跨焦点算 AUROC。折间估计偏移会影响排名，尤其每折仅20焦点。一个不看 embedding、每折只输出训练祖先频率的基线，按同样合并方法也只有简单约0.360/困难0.371；在同一解码器测试折内比较则恰为0.5。因此原打乱标签0.327/0.361不能直接当作正常随机基线。

重新只比较同一折内的正负焦点对，按每候选可比较对数加权，再宏平均候选；另排除拓扑上不可能成为祖先的候选。三个节点划分 seed 均值：

| 祖先 AUROC | 简单 | 困难 |
|---|---:|---:|
| 原合并 embedding | 0.870 | 0.887 |
| 同折比较 embedding | 0.888 | 0.897 |
| 同折比较且仅拓扑合法候选，embedding | 0.876 | 0.884 |
| 同折比较且仅拓扑合法候选，固定随机向量 | 0.550 | 0.532 |

随机向量只有一个向量 seed、三个划分 seed，不是大样本显著性检验。即便如此，祖先相关结构的正面证据仍保留，不应把整组 probe 结果否定。另一方面，原全候选指标仅用拓扑 rank 就有0.813/0.883；限制候选后 rank 为0.642/0.711。应同时报告方向限制与结构基线，不能仅凭0.887声称恢复完整祖先集合。

## 5. YES/NO 是否使用祖先一路仍待因果验证

祖先可读、终点位置重要、仿射 FFN 可替换，三者不等价于祖先方向是答案中介。节点身份、深度、后代/其他图特征、已经混合的源目标信息，都可同时解释位置消融。原文末尾承认尚不清楚 attention 读取哪个子空间，这与开头“YES/NO 用祖先一路”的确定表述不一致。

查询 FFN1 输入是 `LN2(e + Attention1(LN1(e,...)))`，不是原始 embedding。简单图目标位置第一层 attention 已显著读取起点；不能把目标 FFN1 都解释成无上下文地抄写目标祖先集合。单节点关闭 attention 的诊断分布不能直接替代真实查询计算路径。

logit lens 在简单 L2 / 困难 L5 变得能答题，只定位到原输出头何时能读出，并不证明唯一信息汇合点或该层必要性。分隔符全层 FFN 去掉后困难 BA 仍从0.976下降到0.920，不能称完全不承担关系计算；且此前只去第一层分隔符 FFN 会下降到0.751，呈非单调消融效应。不能将联合消融的小效应直接当每层无作用。

## 6. 其他可确认的实现/对照问题

- `fit_mlp`（study.py:358–392）恢复验证最佳 state 后，没有重算训练 recall；返回的是恢复前最后一次的训练 recall。因此“所评估 MLP 训练 recall=1”的证据不严格对应最佳 checkpoint。需要同时记录 best-state train/val/test，而不是以最后训练 state 解释最佳 state 的测试失败。
- `crossfit_knn`（study.py:425–432）用 train+val 的80个节点作 gallery，不是文中统一描述的60个训练节点。不是测试泄漏，但支持量不同，应明确。
- endpoint 小 MLP 的0.964/0.975是额外监督训练的解码器性能，原查询划分中端点身份仍见过。没有同容量固定随机身份向量/one-hot MLP 对照，不能把高性能唯一归因于原 embedding 已包含答案关系，也不能说明原模型实际采用该关系编码。
- 本次只覆盖两个 Direct checkpoint；不能外推 PATH/DFS/BFS，更不能外推新图泛化或跨训练 seed。

## 建议保留的结论

训练后的节点 embedding 有可泛化到 probe 留出节点的祖先相关结构。原模型通过训练过的 embedding、FFN 和 tied head 组合提取后继；这些新解码器尚不能在留出节点上重建同等精度的后继映射。真实 Direct 查询上，节点位置 FFN 对关系判断重要，attention 对跨位置组合必要；仿射映射可以在当前分布上较好替代 FFN。知识的排他存储位置，以及祖先子空间是否是 YES/NO 的因果中介，仍未确定。
