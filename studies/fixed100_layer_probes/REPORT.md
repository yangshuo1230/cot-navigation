# N100 Fixed DAG：简单/困难图的答案读出与结构探针

已完成四个冻结 checkpoint 的分析，没有重新训练主模型。
所有推断和线性读出拟合都在 GPU 0 完成，不创建 W&B 实验或保存探针权重。
仅保存三个关键图、汇总表、逐查询生成与结果 JSON，不保存 activation 中间文件。

## 1. 选择的模型与比较边界

| 图 | 协议 | 主训练预算 | 按验证选择的 best 步数 | 正向查询测试数 |
|---|---|---:|---:|---:|
| 简单分层 DAG，N100/M150 | Direct | 125k | 10k | 1,091 |
| 简单分层 DAG，N100/M150 | Path | 125k | 20k | 1,091 |
| 困难非分层 DAG，N100/M200 | Direct | 125k | 35k | 555 |
| 困难非分层 DAG，N100/M200 | Path | 125k | 10k | 555 |

简单图选择 `fixed_short3_v1/short3_n100_s0/all_hops` 中的全跳数、单固定图对照，
不是三跳限制分支，也不是多世界规模混合模型。简单模型训练还含反向负例；
本次排除这类查询，主评测只比较两种图都有的正向查询。模型反向训练曝光仍是差异。
简单图/困难图的查询划分目标比例分别为 50/20/30 与 70/15/15，WORLD 前缀
分别为 1/0 token，上下文上限 4096/32768，WALK 数也不同。
因此结果是已有 checkpoint 的行为和表征比较，不是仅改变图结构的严格消融。

两类主模型参数架构相同：6 层、1 个注意力头、d_model=128、d_ff=512。

## 2. 测量定义

* **原生最终答案**：从 QUERY 开始自由生成，使用模型实际 YES/NO 答案评分。
* **按层答案读出**：冻结 activation，拟合一个仿射线性分类器。使用类别平衡的
  ridge least squares，正则强度按 probe 验证 AUROC 选择，阈值仅在验证集选择。
  这里是 balanced accuracy / AUROC，不是截掉上层之后主模型的实际准确率，
  也不是经过校准的概率。每一层、每个进展点单独拟合。
* Probe 使用原始 train/val/test query 划分，同一查询的所有前缀始终归于同一集合。
  Path 全部使用 checkpoint 自己生成的前缀，不使用正确答案指导的参考路径。
* 提取输入只包含 prompt 和已生成的轨迹，不含未来 YES/NO。
* E 为当前 token 的原始 embedding，L1–L6 为各 block 后 residual，before final norm。
  prompt 处的 E 是恒定分隔符 embedding，不等于“起终点 embedding 拼接”。
* 正例跳数使用真实最短有向路径。负例没有有限有向跳数，单独报告负例准确率。
  `answer_readouts_by_hops.csv` 给出按正例跳数组合划分的逐层读出；其 accuracy 是
  正例 recall，必须结合负例与 balanced accuracy 判断，不能把恒定 YES 当作高能力。

## 4. Direct：答案随层数何时变得可线性读出

位置为 QUERY 后的分隔符 `|`。数字为测试 balanced accuracy。

| 图 | E | L1 | L2 | L3 | L4 | L5 | L6 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 简单 Direct | 50.0 | 72.8 | 90.5 | 91.9 | 92.4 | 92.9 | 92.9 |
| 困难 Direct | 50.0 | 52.4 | 80.2 | 89.9 | 91.4 | 96.4 | 97.4 |

简单模型的答案较早出现在可读方向上；困难模型在这组 checkpoint 中随后几层
继续提高。此结果只表明读出可用性，不能确定每层完成了一跳搜索。
打乱标签对照的读出总体接近 50%。

## 5. Path：随 CoT 进展的变化

取 L6 的仿射读出，仍是 balanced accuracy：

| 自由生成前缀进展 | 简单 Path | 困难 Path |
|---|---:|---:|
| 尚未生成 CoT，prompt 分隔符 | 73.7% | 70.8% |
| k=1，第一个节点 | 85.3% | 91.7% |
| k=2 | 90.6% | 94.5% |
| k=4 | 93.4% | 95.5% |
| 25% | 90.9% | 94.6% |
| 50% | 94.7% | 96.9% |
| 75% | 97.1% | 97.8% |
| 最后一个轨迹 token，尚未输出答案 | 98.2% | 99.2% |

两个 Path checkpoint 在全部测试查询中的第一个输出均为起点。
因此 k=1 还没有沿边移动。困难模型 70.8%→91.7% 的变化已经发生在这一步，
支持额外计算、信息搬运或位置角色变化等候选解释，而非证明已经展开了搜索。

需要两个控制：

1. k=2/4/8 只统计轨迹至少有这么长的查询，样本池变化。k=8 的测试池分别
   只有 193、203 条，不可直接当成所有查询的时间曲线。
2. 25/50/75% 是按最终轨迹长度回顾性选位置，不是一个不知道未来长度的在线
   停止规则。前缀长度本身也与标签相关。困难图 50% 处，仅位置/目标出现控制
   就达到 82.3%，而 residual 读出是 96.9%。结尾控制为 99.3%，足以解释大部分
   结尾高分，因此不能只用结尾 readout 证明推理形成。

在目标尚未出现在 CoT 的子集中，困难图 25/50/75% 的 L6 读出仍约为
94.6%/96.9%/97.8%。同样需要保留长度与节点身份对照。

## 6. 重要的节点身份对照

起点、终点 embedding 的拼接可以被线性读出答案，但这不自动证明 embedding
编码了关系：100 个节点的 128 维 embedding 足以充当节点身份编码。
因此增加只使用 source/target one-hot 的仿射分类器：

```text
score(s,t) = source_bias[s] + target_bias[t] + intercept
```

它没有单独的 (s,t) 配对 lookup，也没有图搜索。正则和阈值仍只按验证集选。

| 输入 | 简单图 BA | 困难图 BA |
|---|---:|---:|
| 起终点 one-hot | 82.8% | 91.6% |
| 起终点随机 embedding | 82.8% | 91.4% |
| Direct 训练 embedding 拼接 | 83.6% | 92.2% |
| Path 训练 embedding 拼接 | 84.2% | 90.9% |

这是明显的统计 shortcut 风险：困难图仅凭两个端点各自的可达倾向就能达到很高
分数。原始 embedding 拼接高分基本没有超过这一对照，不能单独称为学会关系。
Direct L6 仍高于这一基线，但这些结果不支持将全部准确率归因于复杂搜索。

## 7. Embedding 和浅层 activation 中的结构信息

Probe 目标包括：给定分组/层编号、内部拓扑 rank、从任一源节点出发的最长路径
深度、到任一汇节点的最长路径高度、入度、出度、祖先数、后代数。
困难图没有唯一“DAG 层级”，其 rank_band 是生成器属性；最长路径深度是另一个
实际结构量，二者分别探测。

普通 query-disjoint 结构 probe 仍可能记忆相同节点的属性。主结论因此采用
**node-disjoint probe**：100 个节点随机分为 60/20/20，同一折的训练/验证/测试
查询要求两个端点都在对应节点集合中。重复三种随机划分。主模型训练仍见过所有
节点，这里留出的是 probe 训练身份，不是主模型的未见节点泛化。

下表为留出节点后的 embedding 读出平均 R²（3 折，不是分类准确率）：

| 图 / 模型 | 给定层/分组 | 实际深度 | 祖先数量 | 出度 |
|---|---:|---:|---:|---:|
| 简单 Direct | 0.56 | 0.59 | 0.60 | 0.11 |
| 简单 Path | 0.58 | 0.58 | 0.46 | 0.23 |
| 困难 Direct | 0.06 | 0.46 | 0.52 | -0.05 |
| 困难 Path | 0.57 | 0.68 | 0.71 | 0.27 |

随机 embedding 和打乱节点属性的对照总体接近或低于均值预测；完整各折指标
及标准差在 CSV / JSON 中。说明部分实际深度、祖先数量的可读性超过任意节点
编码的记忆，尤其是困难 Path 的 embedding。三个折中的测试节点最多 20 个，
这些数值不适合作为精确的跨图总体估计。

分隔符处并非所有属性都在第一层可读。例如困难 Direct 的目标节点属性：

| 位置 | 实际深度 R² | 祖先数量 R² |
|---|---:|---:|
| 分隔符 L1 | -0.21 | -0.21 |
| 分隔符 L2 | 0.56 | 0.61 |
| 分隔符 L6 | 0.57 | 0.46 |

困难 Path 的分隔符对同一组目标属性并未得到稳定的留出节点线性读出，
尽管它的原始节点 embedding 本身可读。这说明信息的存在位置和读出方向需要
分别测量；某个位置读不出，不等于模型完全没有该信息。

## 8. 可支持的机制判断与限制

* 固定图的部分结构知识确实以可线性推广到 probe 留出节点的形式存在于 embedding。
* Direct 的分隔符答案 readout 随层数增强；困难模型中增强持续到后几层。
* Path 的答案 readout 随生成前缀增强，但起点复制、位置/长度和目标出现都解释了
  一部分提升；需要因果干预才能证明路径运算对答案的必要性。
* 当前困难图存在强端点身份统计基线。后续基准需要控制端点可达倾向，并继续
  控制完整 witness 曝光，才能更有力地区分搜索与 shortcut。

本次没有做模型截层、激活 patch 或重新训练。线性可读性不等于模型实际使用了
该方向，测试读出低也不排除非线性表示。旧/新图的监督分布和 checkpoint 步数
差异也限制了因果比较。
