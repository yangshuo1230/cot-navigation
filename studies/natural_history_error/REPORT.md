# 自然生成 CoT 的错误读出

四个旧 scale_v1 N100 validation-best 模型冻结。每模型训练/验证/测试分别192/96/256个原始查询，严格按原数据划分。正式轮次 max_new_tokens=0，沿用模型完整上下文预算与原 cot_margin/STOP 规则；未额外加入1024 token截断。最初的1024 token试跑保存在服务器 pilot_1024，正式统计不混入试跑。

## 两类测试

1. **严格修复对照**：错误分支及后续全是模型贪心生成。定位第一个非终止语义错误，从合法 token 集合按固定种子均匀抽取一个修复 token，不看未来选择修复。只替换该 token，后续 token 保持完全一致。每个读出位置只保留修复后从开头到该位置仍合法的配对。该设计能隔离单个历史错误，但自然错误往往使后续也改变，因此晚期样本很少。

2. **纯自然轨迹分类**：正负输入都来自未经修改的自然生成。正例是在首错及其后的位置，负例是完整合法的生成前缀。按语法字段、优先同 token 身份、尽量相近的推理位置和 prompt 长度匹配；每个 anchor 每查询最多贡献一个正例、一个负例。这一测试允许后续错误传播，回答能否分类“此前至今已发生错误”，不单独证明记住了过去错误。

两类测试的首错与读出均排除 FOUND/EXHAUST、STOP、YES/NO/EOS；读出是消费该位置 token 后的 block residual。“错误当场”不是预测错误是否将要发生。所有非终止字段均按图关系与实际动作状态做语义检查，接受不同集合顺序和合法 PUSH 选择。人工迁移使用上一轮 CAND 单节点错误训练分布；自然错误训练另拟合新探针。

Linear/64 hidden GELU MLP，600步，3个初始化，验证 BCE 选择；自然轨迹提取使用 FP32、关闭 TF32。严格配对使用 BF16并同批配对，错前残差最大差为0。冻结导航权重未改动，不保存探针权重或 activation。

## 错误当场的严格修复对照

| 模型 | test配对 | 自然训练 L6 MLP | token身份对照 | 人工训练→自然 L6 |
|---|---:|---:|---:|---:|
| 新图 DFS | 176 | 0.689 | 0.544 | 0.358 |
| 新图 BFS | 215 | 1.000 | 1.000 | 0.208 |
| 固定图 DFS | 31 | 0.754 | 0.817 | 0.667 |
| 固定图 BFS | 8 | NA | NA | 0.526 |

新图 BFS 的单 token 修复会把过早输出的分隔符替换为缺失候选节点；token身份本身就能分清这两个分支，因此高 AUC 不构成错误意识证据。固定图 DFS 的当场残差读出也没有超过 token 身份对照。人工 CAND 节点探针迁移到不同类型自然错误的低 AUC 也不代表完全没有信息，而是原评分方向/训练分布不适用。

新图 DFS 在 +4 token 处明显超过这两种对照，但 +16/+64 已不能超过仅位置对照；固定图 DFS 的后续 VIS 有高于对照的初步信号，测试每类仅22–24个样本，且可能读到错误传播后的状态。新图 BFS 主要漏候选后直接 EXHAUST，缺乏非终止后续；固定图 BFS 的训练首错仅8个，不拟合自然错误探针。

高于0.5但不超过 token/位置对照时，不能将信号解释为图信息与历史的整合。即使高于对照，纯自然轨迹分类也可能利用持续出现的当前状态错误，需要严格修复对照才能进一步隔离过去错误。

| 固定图 BFS | 8/8/8 | 1/0/0/0 | 0/0/0 |

测试集完整生成覆盖（包括在读出测试中主动排除的终止动作错误）：

| 模型 | 首错为非终止 token | 首错为 FOUND/EXHAUST | 生成前缀未见语义错误 | 原生成预算用尽 |
|---|---:|---:|---:|---:|
| 新图 DFS | 176 | 0 | 80 | 0 |
| 新图 BFS | 215 | 0 | 41 | 0 |
| 固定图 DFS | 31 | 0 | 225 | 0 |
| 固定图 BFS | 8 | 2 | 246 | 0 |

自然训练要求 train≥20、val≥8、test≥8 配对；不足时标 NA。原始迁移指标即使样本不足也保留在 CSV，不能作为稳健结论。首错统计排除了终止动作错误，因此不是全部轨迹错误率；用尽上下文前未出现非终止错误的轨迹也可能答案错误。同一固定图的查询并不等于独立图泛化。各 anchor 独立拟合探针；token偏移与后续记录是不同位置，不构成同一条单调遗忘曲线。误差棒仅为探针初始化标准差，不是查询抽样置信区间。尚未测试自动纠错或证明模型会主动使用读出的信息。

两个独立 CPU 状态机校验分别检查全部严格配对和纯自然读出前缀，验证记录见 verification.json 与 stream_verification.json。
