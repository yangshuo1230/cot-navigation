## 搜索过程

原查询为I→P；为阅读方便，显示别名将I、M、P标为A、B、C，其余节点使用D至P。`animation_data.json`的`display_aliases`保留映射，`metadata.json`保留原名字和模型token ID。别名只是显示文字，没有改变输入或节点embedding。

```
R1: A   | A     | B C | PUSH B ;
R2: A B | A B   |     | POP ;
R3: A   | A B   | C   | PUSH C ;
R4: A C | A B C |     | FOUND ;
YES
```

模型读入全部16节点/24条边的原始prompt，只访问3个节点。默认图视图放大这3个节点，可切换完整16节点。图上的状态从生成序列解析且经过严格重放，不是隐藏状态探针输出。72个边token+4个查询token+40个输出token，共116token。

## 注意力视图

1. 当前预测：实际消费的位置p对应attention query，预测实际生成的p+1；显示top-8 key及其总质量，保留重复token的绝对位置与字段身份。
2. 六层统计：按图结构、查询、当前状态、历史状态、自身等分组求和，每层合计100%。自身位置优先单列，其余分组互斥。
3. **搜索时的边列表读取**：24条原始输入边全部展示；逐边列出EDGE、起点、终点及合计权重。没有按边列表质量重新归一化，随播放与层切换更新。GIF底部也展示这部分。
4. **输入边列表内部attention**：每层24×24边块矩阵。一个3×3块对3个key列求和，再对3个query行取平均，每个聚合行和为1。点击格子查看原始3×3权重，包括因果遮罩。输入前缀在因果模型中不会因后续搜索变化，因此此矩阵随层切换、而不随搜索帧变化。

`edge_encoding.gif`是内部矩阵的六层轮播，`edge_encoding_layer4.png`是第4层静态图。统一0–1概率范围、平方根颜色映射，未逐行重缩放。

原始attention保存在`attention.npz`；checkpoint哈希、数据路径、选择记录和语义重放结果分别见`metadata.json`与`selection.json`。模型没有重新训练，也没有占用GPU。

## 逐 token 历史信息追踪器

新版优先回答“这个具体位置关注谁、那个历史位置此前关注谁”。六层全部116×116原始矩阵嵌入页面，共80736个数值，不限于top-8或轨迹动作。

- 左侧按输入边、查询、完整状态记录分组，全部token（包括分隔符）均可直接选择。支持字面值、字段或`#绝对位置`搜索。
- 中间按图EDGE/边起点/边终点、查询、stack、visited、候选、动作、动作参数、格式符号分类；类别质量由所有对应位置求和。点击类别过滤具体token。列表可按权重或序列位置排序，默认16项，可展开全部可见位置，没有对列表重新归一化。
- 点“上下文”显示所选key的原始token ID、周围token和完整记录/边。节点另列出它在全序列的所有出现位置及原始输入图中的前驱/后继；图事实不是隐藏状态读出。
- 点“追上游”时层数自动减1：L4位置p读取的是L3位置k的value表示；继续查L3@k读取了哪些L2位置，直到embedding。保留带权重的每次路径，支持返回、前进、点击任意路径卡片及一键重置。
- “后面谁读取它”查看下一层各query对当前表示的attention列，追下游时层数自动加1。该列跨query不归一化，类别质量的和可以大于100%。
- “演示追两级”从L4@102 PUSH开始，按每级最大权重选择L3@100 C、L2@99 visited结束分隔符。这里只是演示查阅方式，不把最大权重路径认定为因果回路。
- 折叠区保留完整token×token矩阵，每个格子可点击定位query并查看key。

L0边界无上游attention，L6边界无下一层attention。该视图只追踪attention的value读取关系；没有将Q/K依赖、FFN和残差通路合并为完整计算图，不将逐边权重相乘解释为因果贡献。

构建：`python build_token_explorer.py`。生成器读取本目录原始npz及既有语义元数据，不重新调用模型。`build_animation.py`现只输出`search_animation.html`，避免覆盖主追踪入口。

浏览器验证252种位置/层/方向组合，116个可选token、全部来源展开、分类过滤、历史边上下文、跨层多级追踪、返回前进及搜索通过；完整矩阵13456格及点击下钻通过；430px布局无页面横向溢出；无运行异常。证据：`token_explorer_verification.json`，截图：`token_explorer_preview.png`。
