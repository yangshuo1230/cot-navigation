# 同起点供体：控制目标状态中的起点混杂

原实验供体为 d=(sB,tB)，接收为 a=(sA,tA)。这既改变目标也改变供体上下文的起点，不能把状态移植当作只改变目标祖先信息。简单图的目标 L1 明显依赖起点；困难图 L1 依赖很弱，但不是严格为零。

| 原生目标 L1 的注意力 | 简单图 | 困难图 |
|---|---:|---:|
| 起点位置 | 38.924% | 0.02695% |
| 目标自身 | 12.430% | 99.97179% |

目标位置 L1 的完整状态来自同目标、不同起点的供体时，答案按供体关系改变的比例为简单图 89.1%、困难图 0%。这些是有限测试面板上的观测，不能由此断言困难图完全没有起点信息。

## 补充实验

供体改成 b=(sA,tB)，与接收查询起点完全相同。沿用原 W、SVD 定义和相同测试面板，固定内部 L1，扫描 rank 1/2/4/8/16/32/64。原查询与供体查询都属于原 test。原四问全答对的机制子面板，简单图 n=238、困难图 n=119，分母保持不变。

P 为祖先探针 W 的前 r 个左奇异向量的投影，delta=(h_b-h_a)P。分别编辑 h_a+delta、h_b-delta，再重算后续层。随机方向逐样本匹配祖先方向编辑范数，3 个随机种子；rank32 另有同范数打乱祖先对应关系的控制。

| L1 / rank32 | 简单图：按新目标改变答案 | 困难图：按新目标改变答案 |
|---|---:|---:|
| 只移植探针前32维子空间 | 0.0% | 1.7% |
| 只移植其余96维子空间 | 99.2% | 99.2% |
| 等范数随机方向，3 seed均值 | 0.7% | 0.8% |
| 等范数打乱祖先方向，3 seed均值 | 0.0% | 0.0% |

祖先方向编辑让起点对应的祖先成员读出分数平均朝新标签移动 +0.927（简单）/+0.894（困难），而其余方向编辑为 +0.015/+0.066。以上是未校准 ridge 分数，不是概率。二者维数和编辑范数不同，不把32维与96维效果直接当作公平的因果强度比较。

简单图原先跨起点供体下，其余方向编辑仅5.9%按新目标改变；同起点后为99.2%。这一差异说明原先的跨起点上下文混杂确实影响了结果。不能用原先的低比例断言其余方向不重要。

## 起点是否被破坏

- 原始起点 token 在目标之前，因果注意力阻止目标编辑反向影响起点位置。两条同起点自然查询的源位置 E～L6 activation 差异为0。
- 目标位置中可以有起点信息的副本。即使用同一起点供体，部分子空间混合仍不保证保留这些语义信息，尤其是节点身份与图信息可能纠缠。
- 补做目标 L1→起点身份的线性探针，按原 query train/val/test 拟合。机制测试子面板的原始基线准确率仅26.5%（简单图）、0%（困难图），不足以可靠验证“起点信息完全保留”。简单图基线答对的63例中，祖先方向编辑后19例仍能正确识别起点；此子集上的答案反事实改变率仍为0%。这些是干预后筛选，不与不同方法的不同子集作公平比较。

因此，同起点供体控制排除了主动移入另一个起点的混杂，但没有实现对祖先语义的完美独立操纵。稳妥结论仍是：这个线性探针定义的前32维子空间读出变化，与模型答案变化可以分离；不能扩大为对所有祖先表示的证伪。

完整数据：simple_same_source.json、hard_same_source.json。代码：same_source_control.py。冻结前向 GPU1，线性拟合 GPU0，无新增模型 checkpoint 或 activation 文件。
