# Stepwise Inference 固定图近似文献基线

来源：https://arxiv.org/pdf/2402.07757 ，§2.2、§3.1、附录 C.3/D。

目的：在知识与任务共享查询接口的情况下，检查固定图查询泛化及 PATH 拼接优势。此批次是近似文献基线，不宣称精确复现，不替换现有邻接表实验。

## 12 个任务

3 张随机固定分层 DAG × Direct/PATH × random20/short3。每张图 200 节点、10 层各 20 节点，相邻层独立以 p=.05 连边，节点名随机置换。

全部一跳边作为正 QUERY 样本训练；没有独立 ADJ/WALK 阶段，没有 grokking 门槛。

- random20：随机选择 20% 可达端点对，再补齐全部一跳边；所选正对的全部简单路径加入数据。加入与正对数量相等的不可达端点对。
- short3：只从跨度 ≤3 的正对中选取 20%，再补齐全部一跳边；测试正对跨度 ≥4。训练负对按相同数量从全部不可达端点对采样，监控/最终负对限制跨度 ≥4。
- 正负标签平衡按端点对计，不承诺按序列平衡。枚举所有路径后按序列均匀采样；Direct 保留同样的路径重复次数，确保两种协议底层查询权重一致。路径更多的端点对权重更大。
- 监控和最终测试按端点对分离、各自正负平衡。保留全部未选正对的 25% 作 monitor，余下为 final；负例无放回配对。仅最终步读取 final。
- random20 的负例含逆序和同层等易例，因此同时报告 forward_only（层差 >0）以及逐层差指标，避免总体成绩掩盖顺序捷径。
- 测试端点对未直接进入训练，但可能是训练路径子路径；manifest 明确统计该暴露，不称为严格 witness 隔离实验。

## 模型与优化

按论文表1：2 层、宽64、FFN256、GELU、可学习绝对位置、context32、无 dropout、线性层无 bias、输入输出权重共享、Adam betas(.9,.95)、LR1e-4、batch64、全序列 next-token CE（只屏蔽 padding）。序列为 BOS target start [PATH 中间点及 target] YES/NO EOS。节点词表200，5个特殊 token。

每次更新采样64条完整序列。固定125,000步，监控每5,000步，checkpoint每25,000步；另报告所有一跳边的 QUERY 召回及 PATH 正例路径有效率。生成使用全词表原生 argmax，不用答案约束、邻接过滤或目标长度 oracle。PATH 最多12个新token，超过预算或提前EOS均算失败。

## 明确的实现选择与偏离

1. 论文未充分指定头数、学习率调度和样本权重：本批选择4头、恒定LR、按序列均匀采样。125k步沿用本项目固定预算，非论文声称的精确预算。
2. 按论文图12文字采用 attention 前 LN 与 MLP 前 LN（文中称 post-LN），并使用最终 LN；并非原作者代码逐行复现。
3. 论文算法2要求图 connected；200节点、层间p=.05的全节点连通条件非常苛刻。本批使用未条件化采样，不添加保底边、不剔除孤立节点，也不声称满足该连通条件。数据文件和实际边数完整保存。
4. 使用 CUDA bf16、梯度范数裁剪1与 torch.compile，是实现选择。
5. 一图一模型seed，3次图/初始化联合重复；不能将其当作同一图上的3个初始化重复。

只使用 GPU0–5，两张既有 grokking 卡保留。输出独立目录 outputs/stepwise_reference_20261024，W&B group stepwise_reference_20261024。
