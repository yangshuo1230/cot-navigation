# Fixed DAG：FFN 存图，还是在处理图

结论：两件事都发生，但不是同一种图信息。直接后继主要记在 FFN 权重里，embedding 只是地址。祖先集合已经在 embedding 里，FFN 把它线性写进残差，不再另存一份。可达性答案可以由两个端点的 embedding 算出来；模型里的 FFN 负责把这些特征写进残差，attention 再把起点和终点合到分隔符上。在真实查询上，这个 FFN 可以换成线性映射，答案基本还在。

## 怎么区分

FFN 是逐位置的。它看不见另一个 token，除非 attention 已经把那个 token 混进当前残差。因此：

- 说 FFN **存储**后继，是指训练过的权重实现了一张按 embedding 向量取后继的表。换一套随机 FFN，原输出头就读不出来；用其他节点重新拟合解码器，也预测不了留下的节点。
- 说 embedding **存储**祖先，是指留下的节点上，线性探针、近邻和重新训练的 MLP 都能读出祖先，而且 FFN 增量里与输入线性无关的方向不再含有祖先。
- 说 FFN **处理**答案，是指关掉它会伤到 YES/NO，但查询分布上的 FFN 输入已经线性决定了它的输出。它不是在查询时再查一张非线性关系表。

模型是两张 N100 Fixed DAG 的 Direct 验证最佳 checkpoint：简单分层图 10k 步，困难图 35k 步。简单图训练含反向查询和一个世界 token，上下文 4096；困难图没有这些。两张图的差别不能单独归因于图更难。主模型见过全部节点。节点留出只约束这次新拟合的探针和解码器。原输出头不是留出评估。

冻结 FP32、CPU、math attention。没有改训练代码，没有保存 activation、探针或新 checkpoint。与已发表数字对齐的单节点后继 recall、测试准确率和 FFN1 位置消融，都复现到小数点后三位；本次测试预测与原先保存的预测一致率为 100%。

## 后继在 FFN 权重里

单节点输入，attention 残差置零，只留 embedding 和 FFN。指标是非空出度节点的 recall@真实出度。简单图随机水平约 1.5%，困难图约 2.0%。下表是 3 个节点划分种子的均值。宽 MLP 和瓶颈 MLP 的训练 recall 都接近 1，所以低测试分不是没拟合上。

| 读出 | 简单图 | 困难图 |
|---|---:|---:|
| 原头直接读 embedding | 1.2% | 1.2% |
| 原头，训练过的 FFN，第 1 层后 | 97.5% | 51.8% |
| 原头，训练过的 FFN，第 6 层后 | 100% | 65.6% |
| 原头，随机初始化 FFN，第 1 层后 | 2.5% | 1.6% |
| embedding 线性探针，留出节点 | 13.0% | 12.9% |
| embedding 的 5 近邻 | 18.6% | 11.6% |
| embedding 上重新训练的宽 MLP | 15.9% | 14.2% |
| 打乱后继标签的线性探针 | 0.4% | 2.0% |

把节点的输入向量互换、输出头保持不动，原头读到的后继跟着向量走：简单图供体 recall 仍是 97.5%，按原 token 身份计只有 3.0%。换成随机向量则掉到 6.7%。困难图第 1 层同样从 51.8% 的供体 recall 掉到按原身份计的 8.0%。FFN 认的是向量，不是 token 编号。

embedding 的离对角余弦均值接近 0，但简单图有 64 对、困难图有 102 对余弦大于 0.5。这些近邻对的后继 Jaccard 均值只有 0.21 和 0.09。几何上靠近并不表示后继相同，留出解码器也学不会这张表。因此 embedding 里只有很弱的后继信号；能让原头读到 97.5% 的，是训练过的 FFN 权重。

FFN 写进残差的向量，用新的线性探针只能读到一部分后继：简单图从 embedding 的 13.0% 升到第 6 层的 42.8%，困难图升到 23.8%，都低于原头。把每一层 FFN 增量对 LayerNorm 输入做线性回归后，剩下的正交方向只有约 4–14%。原头能读、新探针读不全，是因为原头就是 embedding 表本身：FFN 把地址变到与后继 embedding 对齐的方向，点积正好落在后继 token 上。新探针要在 60 个训练节点上重新学这个方向。

## 祖先在 embedding 里

指标是固定候选节点、跨焦点节点的列 AUROC。每个节点一行，排除自己。3 个种子。

| 读出 | 简单图 | 困难图 |
|---|---:|---:|
| embedding 线性探针 | 0.870 | 0.887 |
| 5 近邻 | 0.830 | 0.839 |
| 重新训练的宽 MLP | 0.827 | 0.880 |
| 打乱祖先标签 | 0.327 | 0.361 |
| 原头，第 1 层 FFN 后 | 0.576 | 0.564 |
| FFN 增量的线性部分，第 1 层 | 0.864 | 0.891 |
| FFN 增量里与输入正交的部分，第 1 层 | 0.491 | 0.523 |

祖先可以从留下的 embedding 线性读出，近邻和 MLP 也接近这个水平。原头几乎读不出祖先，说明它不是靠“输出祖先 token”来保存这张表。第 1 层 FFN 增量里的祖先信息留在输入的线性像里；正交方向回到零假设附近。简单图最终残差里、线性剔除 embedding 之后的列 AUROC 是 0.377；困难图是 0.591，仍低于 embedding 本身的 0.887。FFN 没有再存一份祖先表。简单图上，残差探针的祖先 AUROC 还从 0.870 降到第 6 层的 0.713，后续层在冲淡这份线性编码。

## 答案是线性处理，不是另一张关系表

测试查询只看分隔符上的下一个 token。主指标是 YES/NO 二选一的 balanced accuracy，避免把非法 token 和关系错误混在一起。简单图 1091 条，困难图 555 条。

| 干预 | 简单图 BA | 困难图 BA |
|---|---:|---:|
| 原模型 | 0.931 | 0.976 |
| 关掉全部 attention | 0.500 | 0.500 |
| 关掉全部 FFN | 0.534 | 0.674 |
| 只关掉起点位置的全部 FFN | 0.824 | 0.777 |
| 只关掉终点位置的全部 FFN | 0.487 | 0.699 |
| 只关掉分隔符位置的全部 FFN | 0.895 | 0.920 |
| 用训练查询拟合的线性映射替换全部 FFN | 0.926 | 0.955 |

关掉 attention 后，分隔符只处理 `|` 这一个 token，BA 正好是 0.5。FFN 自己不能把起点和终点合成答案。

简单图去掉终点 FFN 后几乎总答 YES（YES recall 0.951，NO recall 0.024）。去掉起点只降到 0.824。困难图两边都有损伤，一起去掉节点位置时降到 0.596。分隔符上的 FFN 不是主要的关系计算。这和以前只看第 1 层时的分工一致：简单图第 1 层 FFN 在分隔符上主要破坏输出格式（原生准确率 15.3%，二选一 BA 仍有 0.901），在节点上则破坏关系（BA 0.477）。本次全部六层一起去掉时，分隔符 BA 仍有 0.895。

只去掉第 1 层 FFN，简单图 BA 降到 0.540，困难图降到 0.770。去掉第 2–6 层中的任意一层，简单图仍在 0.929–0.932，困难图仍在 0.956–0.976。logit lens 也对得上：简单图的 YES/NO 边际在第 2 层 attention 跳到 0.897；困难图在第 5 层 attention 跳到 0.968。第 1 层 FFN 先把节点特征写进残差，后面的 attention 才在分隔符上形成答案。

两个端点 embedding 拼起来，不经过网络：线性探针在简单图测试 BA 0.827（AUC 0.922），困难图 0.926（AUC 0.974）。一个 32 维瓶颈 MLP，按验证 AUC 早停、阈值只在验证集上选，简单图测试 BA 0.964，困难图 0.975。简单图这个外部解码器高于模型自己的 0.931，说明答案关系已经在两个 embedding 里，模型还没用满。该 MLP 只有一次初始化。

把每一层 FFN 换成其 LayerNorm 输入的仿射函数，拟合只用训练查询的各个位置，惩罚项由验证查询选择。验证集上重建 R² 为简单图 0.935–0.982、困难图 0.954–0.978。换上之后测试 BA 为 0.926 和 0.955，原生准确率 0.940 和 0.955。查询时的 FFN 几乎是线性解码，不是非线性查表。节点孤立状态下的重建 R² 只有 0.28–0.76，那是 60 个节点对 128 维输出，方程不够，不能拿来证明 FFN 非线性。

## 边界

- 每张图只有一个 Direct checkpoint。简单图和困难图的训练配方不同。
- 后继的强读出用的是原输出头，训练时见过全部节点。留出结论来自新解码器的失败，以及随机 FFN 的失败，不是头本身的留出测试。
- 新线性探针读不全后继，不能解释成残差里没有原头能用的方向。
- 置零是分布外干预，不能排除被删掉的分支有冗余替代。
- 这里没有做 Path 的逐步生成。Path 上第 1 层 FFN 已经单独测过当前位置和目标位置的分工，见 `research/fixed_graph_storage_20261022/REPORT.md`。
