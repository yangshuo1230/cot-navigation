# 跨种子 DFS Nodes attention 操作核对

## 结论

可复现的是操作类别，而非固定层号。三个种子都有后置 EDGE 的边记录构造和当前节点出边读取；起终点汇聚顺序、操作层位可以改变。回退时读取历史祖先仍可观察到，但 seed1 更分布式，不能宣称三者都有同一个精确“最近可继续祖先指针”。目标信息的读取路径差异很大；额外的单位置 residual interchange 给出了可替代目标通路的因果证据。

## 设计与分母

- 三个已完成的 simple-family DFS Nodes 模型，seed0/1/2，均取 1,000,000 updates 的 latest checkpoint。没有根据 test 选择 checkpoint。
- 沿用上一批相同 96 个 test 查询：N12/N16/N24 各32题、正负各16题，无生成成败过滤。各 seed 的输入 token 完全相同，允许各自自由生成不同合法邻居顺序。
- 自由生成用于检查真实行为；另在同一条正确参考轨迹上提取三个 seed 的 attention，控制轨迹差异。参考结果是 teacher-forced，不当作模型自由生成成功。
- 在 N12+N16 上扫描全部六层、三个边槽位置（源节点、目标节点、后置 EDGE）选择最强观察位置，再独立报告 N24 上的值。N24 是独立分析核对集，并非模型训练未见的图规模。
- CPU FP32；288 次自由生成全部通过完整前向 greedy 决策核对、权重归一化和因果遮罩检查。自由轨迹只标注首次非法节点之前的合法已消费前缀，包含下一步将错误的位置。

## 独立 N24 核对结果

以下结构注意力数值均为平均权重；出边/祖先为同参考前缀条件，答案准确率和轨迹合法率为各 seed 在全部96题上的自由生成。层位在前64题上选定。

| seed | 答案正确 | 完整轨迹合法 | 后置 EDGE 汇聚 | 正常展开出边读取 | 回退祖先读取 | 目标通路替换（16 对） |
|---|---|---|---|---|---|---|
| 0 | 94/96 | 75/96 | L2 起点 99.4%；L1 终点 99.4% | L4 / relay；52.3% | L5；53.2% | target L3；YES 16→0/16 |
| 1 | 96/96 | 96/96 | L1 起点 97.9%；L2 终点 99.5% | L3 / relay；65.5% | L6；30.0% | bar L1；YES 16→0/16 |
| 2 | 95/96 | 93/96 | L2 起点 99.5%；L3 终点 99.9% | L5 / relay；54.3% | L6；29.1% | bar L2；YES 16→0/16 |

## 对等效操作的解释

1. **边记录构造稳定，但顺序不同。** seed0 是 L1 读终点、L2 读起点；seed1 是 L1 读起点、L2 读终点；seed2 是 L2 读起点、L3 读终点。N24 上所选读取权重均约98%–100%。这支持“用局部位置把两个端点汇聚到一个边槽”的等效操作。
2. **出边查找可以换层或拆成多层。** seed0 主要 L4；seed1 主要 L3；seed2 的 L4/L5 都有明显出边读取。对 seed2，按 discovery 规则只报告其中较强一层的 N24 核对值，不把另一层的观察隐去；完整六层数值在 JSON 中。
3. **祖先查找不能简化成统一指针。** seed0 L5 集中读取祖先；seed1 的 L3/L5/L6 分担历史读取与筛选；seed2 的 L6 明显读取祖先。表中祖先层按祖先总质量选，候选祖先最强层可能不同。历史内 top-1 即使很高，也可能只有很少总 attention，不能与 global top-1 混为一谈。详细 candidate 指标在 analysis.json，全部层在 summary.json。
4. **目标比较不必表现为末层直接读目标 token。** seed0 直接目标读取；seed1 的目标相关信息在很早的分隔符位置就已影响当前位置；seed2 显示目标信息经分隔符再传入后续生成位置。注意力指向不同，但都能支持相同的“当前节点是否目标”行为。

## 目标通路：可审阅的因果检查

对预先选定的48个正例，使用参考 DFS 已到原目标的前缀，且仅把 QUERY 的目标换为尚未访问过的其他节点（优先同层带，选择不看模型分数）。图和全部已消费节点保持相同；修改后的历史仍是合法 DFS 前缀。此时原查询应停止并回答 YES，新目标查询不应回答 YES。

三个 seed 均为原前缀 48/48 预测 YES、目标替换后 0/48 预测 YES。没有用模型分数筛选配对。对每一对，仅替换一个位置、一个完整 block 输出后的 residual，后续照常重算；比较目标位置、查询末尾分隔符和当前节点三类位置、全部六层。

- seed0：替换目标位置 L1–L5 后的状态，全部48对均停止预测 YES；分隔符替换基本无效。与 L6 直接读目标相符。
- seed1：替换分隔符 L1 后的状态，48对均停止预测 YES；L1 之后再替换目标位置状态基本无效。替换当前节点 L2 后状态同样48对改变。这支持早期经分隔符传递的替代路径。
- seed2：替换目标 L1 后状态，或分隔符 L2/L3 后状态，48对均停止预测 YES；替换当前位置 L4 后状态47/48改变、L5后48/48改变。这支持经分隔符进入后续当前位置的替代路径。

这些是改变终止/YES决策的定向证据，不是完整导航成功率干预，也不证明替换位置只携带目标身份。早期 current swap 被之后重新读入原始信息覆盖是可能的；不能把“某层替换无效”解释为该层没有目标信息。所有配对均检查同状态 sham 为严格 noop、末层非当前位置替换为 noop、末层当前位置替换精确复现 donor 的输出 margin，共144组控制通过。

## 限制与文件

只检查这三个同配方 seed、simple DAG 的 N12–N24；不推断 hard DAG、其他架构或所有随机初始化。层的挑选属于预先限定的操作族内搜索，N24 单独核对，不把探索结果当作唯一电路。边聚合与祖先操作目前主要是 attention 证据，尚未用相应语义配对干预证明。目标通路有额外激活替换支持。

- summary.json：checkpoint哈希、抽样ID、所有层、自由/参考/发现/核对统计。
- rows.json：逐合法前缀的全部指标。
- target_patch.json：每对目标替换、每层每位置的激活干预与分数。
- analysis.json：按 discovery 选出的操作层及独立核对值。
- explorer.html：相同两条 N16 查询在三个 seed 上的真实自由轨迹，单页面切换，不使用 iframe。
