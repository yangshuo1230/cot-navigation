# DFS Nodes 多轨迹 attention 检查

结论：L1/L2 的边记录聚合非常稳定；L4 当前出边读取与 L5 回退历史读取有明确支持。L3 的祖先定位暂未得到支持；L5 也不是可靠的“最近可继续祖先”指针。L6 直接读取查询目标很稳定，但尚不能据此断言完成了答案匹配。

## 范围与分母

同一个 simple-family seed0、1M-step checkpoint。N12、N16、N24 各预先随机抽取 16 个正例和 16 个负例，共 96 个测试查询。独立于输出和 attention 抽样；CPU FP32 贪心生成，不喂参考轨迹。生成上限 N+4（完整 node-only 轨迹最多 N 个节点及答案，本批次无样本触顶）。全部 96 条完整前向 greedy 选择与自由生成一致。

最终答案正确 94/96，完整轨迹合法 75/96。两指标独立。合法率低于答案准确率，因此不能仅凭正确答案标注搜索状态。下面的搜索统计仅用首次非法展开之前的合法已消费前缀，仍包括“即将预测错误下一步”的位置，也包括最终失败的查询；不统计错误后缀。

共有 424 个合法状态位置：217 次当前节点仍有可展开后继、131 次需要回退、44 次已到目标、32 次搜索穷尽。各位置不是独立样本，以下百分比是本批描述统计，不作为独立重复实验的显著性检验。

## 各层证据

| 假设 | 多轨迹观察 | 判断 |
|---|---|---|
| L1/L2 汇聚边列表 | 2,400 个非末尾边中，下一 EDGE 位置在 L1 读取上一条边终点的平均权重 99.46%，L2 读取起点 99.37%；两层 top-1 命中均为 100% | 强支持分两层聚合边记录 |
| L3 找祖先 | 回退位置平均只有 18.84% 读生成历史，40.72% 读 QUERY 标记；历史 token 内 top-1 命中任一栈祖先 11.45%，命中最近可继续祖先 8.40% | 不支持直接祖先指针解释；不排除其残差或 FFN 参与其他计算 |
| L4 查找当前出边 | 217 个正常展开位置，53.61% 权重读当前节点出边的后置 EDGE；global top-1 命中率 68.20%。131 个回退位置降到 1.53% 权重 | 支持按当前节点读取出边，不能解释成每步都查到最终选择的那条边 |
| L5 找可继续祖先 | 回退时 78.46% 权重读生成历史，而正常展开时仅 13.61%；回退时历史内 top-1 落在栈祖先的比例 96.18%，落在最近可继续祖先的比例 72.52% | 强支持回退相关的祖先读取，精确候选过滤仍不可靠 |
| L6 答案匹配 | 正常展开、回退、到目标、穷尽时，对 QUERY 目标 token 平均权重分别为 99.02%、95.85%、99.75%、98.03% | 强支持直接目标读取；比较/终止判定需通过激活或因果干预验证 |

边记录位于后置 EDGE：`EDGE u v EDGE` 中后一个 EDGE 先读 v，再读 u。最后一条边后面是 QUERY，属于不同边界情形：96 个末尾 QUERY 的 L1 终点权重仅 11.75%，L2 起点权重 27.72%，不能算进普通 EDGE 聚合结论。L4 的出边统计仅计后置 EDGE，不把末尾 QUERY 混作普通边槽；在排除当前节点拥有末尾边的 196 个正常展开位置后，平均权重 55.28%、top-1 命中率 70.92%，结论一致。

## L5 的关键反例

131 个回退位置中，83 个只需回到直接父节点，48 个需要跳过已耗尽父节点。前者正确祖先 top-1 命中 86.75%（72/83），后者只有 35.42%（17/48）。因此“读到了栈祖先”明显成立，但“精确找到最近仍有合法候选的祖先”不能直接成立。始终选直接父节点的结构基线在这批次为 63.36%，L5 实际为 72.52%；这不是复杂因果控制，也不能排除位置和身份线索。

按规模，L5 回退时正确祖先 top-1 为 N12 71.79%（39 个位置）、N16 74.47%（47 个）、N24 71.11%（45 个）；不是原始单条轨迹特有现象。在完整合法轨迹的回退位置上为 73.03%，最终非法轨迹的先前合法回退位置上为 71.43%，不能用这项 attention 指标本身解释所有成败。

## 建议的机制表述

L1/L2 构造边记录 → L3 尚未确定 → L4 读取当前节点出边 → L5 在当前分支耗尽时转向栈祖先历史 → L6 持续读取查询目标。

这批检查仍限同一 checkpoint、simple layered DAG、N12–N24。没有验证其他 seed、hard DAG 或 N100，也没有进行因果干预；attention 分布不等同于表示内容或实际计算功能。探针或配对干预应优先检验“跳过耗尽父节点”这一薄弱环节。

## 文件

- `summary.json`：抽样设计、96 条查询的结果、分规模/状态汇总、checkpoint 哈希。
- `rows.json`：424 个合法前缀的逐层指标和重建栈标签。
- `inputs.json`：2,496 个边槽的输入聚合测量（包括 96 个末尾 QUERY 边界）。
- 六个 `n*_label*_idx*.html`：每个规模预先抽样的首个正/负例，均包含完整输入及生成 attention。N24 正例是答案正确但含重复节点的反例。
