# Scale 后模型的探针与因果干预：主要发现

完成60个主实验模型：新图/固定图，N16/36/64/100及规模课程，Direct、Path、DFS/BFS全状态与节点版。每个run均使用验证选出的best checkpoint，未根据test重新选择。另按验证分数列出DFS/BFS的主变体，并保留另一版本；全状态干预不能代表节点版。新批次没有Filler，只有seed0。

导航权重全部冻结。仅物理GPU0训练仿射探针；冻结模型推理分配到空闲GPU。无导航训练、W&B run、探针checkpoint或activation缓存。各阶段使用的源代码版本和推理batch均有记录。

**最重要的结果是：固定图模型能表示访问历史和部分过滤信息，但不会稳定服从被篡改的外显visited。** 这不等于它在正常轨迹上没有执行搜索，也不能据此认定只是背诵轨迹。

|---|---:|---:|---:|
|新图DFS全状态|0.637 / 0.698|0.594 / 0.482|71|
|新图BFS全状态|0.739 / 0.901|0.535 / 0.459|71|
|固定图DFS全状态|0.967 / 0.915|0.901 / 0.699|62|
|固定图BFS全状态|0.995 / 0.952|0.958 / 0.562|69|

visited在输出列表前读出PUSH推导的历史；后继内过滤在列表后读出，只保留真实出邻居，区分其中已访问与未访问节点，排除了“识别非邻居”这一简单捷径。后者主表使用合法参考轨迹；保存的自然状态大多没有同时包含两类后继，不能把小案例集当成自然生成总体的结论。输入对照只包含当前节点embedding及位置/目标出现特征，不能排除所有查询身份捷径。

新图全状态模型的L6 visited排序AUC均未超过对应输入对照；但后继内过滤仍有可读信号，且随规模并不单调。N36 DFS/BFS参考过滤AUC分别约0.81/0.83，N100静态组降到约0.59/0.54，课程N100约0.75/0.66。完整集合不易读出，与局部候选判断有一定信息，可以同时成立。阴性结果仍受位置、线性读出及探针样本量限制。

**全路线阻断共获得1360个认证状态。** 新图N100静态BFS没有合格状态，不能解释成干预无效。固定图N100 DFS不加入目标的阻断组，原样NO率2.5%，修改后10%；但90%的样本在后续显式PUSH了被标记节点。该组与等量不同死节点对照的YES率差为+10个百分点，95%查询bootstrap区间[-2.56,22.5]，不支持稳定的阻断特异性。

全体配对比较中，6个逐项95%区间未跨0的阻断/死节点差异都表现为加入有用节点反而更容易YES。它们是未作多重比较校正的探索结果，不宜当作稳定规律。最终NO也不自动代表正确搜索，需同时看候选、PUSH及状态更新。外显visited编辑可能与历史矛盾，历史修复与忽略字段尚未区分。

**错误觉察尚无稳定证据。** 例如新图N100 DFS在相同下一个token处，检测前一个token错误的自然测试AUC约0.497；课程DFS/BFS约0.452/0.518。修复后下一步仍合法的子集往往很小；固定图N100 DFS/BFS各只有1个严格配对，不能解释其AUC=1。DFS节点版未误用BFS层级错误oracle，其结构探针和节点干预仍完整保留。

**验证选checkpoint存在值得关注的噪声。** 固定图课程BFS在原有同一批256个测试查询上，验证选出的best准确率85.55%，last为96.88%；两者STOP比例分别33.98%与11.33%。本分析仍坚持使用best，没有按test换模型。这说明小验证集达到100%并不保证选中实际泛化最好的训练阶段。

两批实验还存在训练数据差异：本批每查询预存4条随机轨迹，旧探索在线随机搜索顺序；训练步数、规模混合和WORLD也不同。不能将跨批变化全归因于图变大。

独立CPU校验确认60份checkpoint哈希未变、探针查询划分互斥，复核301个保存的阻断/死节点案例。与原best测试重叠的3744个查询中，3731个答案一致；13处差异可能与BF16批次及生成轨迹变化有关，尚未单独归因，未声称逐token复现。所有配对干预使用本次实际原样续接作为对照。
