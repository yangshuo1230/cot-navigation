## 目标与时序

位置p的activation已经读入x[p]、尚未生成x[p+1]。目标为截至p是否曾发生错误，包含刚读入的x[p]；不是未来是否会错、最终是否答对，也不是错误是否尚未修复。
采集首错记录及之后两条记录的每一个token、每一层残差（共6层）。主输入完全不含MISTAKE。
同一窗口内错误之前的所有标签均为0；错误之前成对activation须完全一致（阈值1e-5）。

## 数据与划分

复用 history_error.build_events：在合法DFS记录中替换一个未被PUSH的候选，改为图内非邻接节点，保留其余文本与之后真实合法动作。故可区分“知道之前状态字段错过”与“看到搜索已经崩坏”。
每个原始查询一个事件；train768对、val192对、test256对。整个原始查询、所有变体、所有token位置不能跨split；另外检查原始带节点名称图的SHA256无交集。
独立外测复用自然错误池test split：还原donor实际生成的候选字段，不携带MISTAKE；覆盖复杂遗漏/多余/重复。测试图排除探针train/val图。
这些donor错误不是当前被探测模型自己自由生成的错误，必须在结果中单列，不将其称为自发错误。
主实验要求非首选候选和足够后续动作，因此偏向非平凡、尚未终止轨迹；结论不涵盖所有导航查询。

## 探针与对照

- 复用公共 ParallelProbe 参数化。对每个(错误记录/后1/后2、记录内token偏移、层)独立训练线性和MLP64，分别2个probe seed，最多5000更新。各cell独立标准化、独立权重/偏置、独立按val BCE选择训练步数，层之间和位置之间均不共享拟合参数。
- 向量化仅用于提高效率，不绑定任何cell的参数。不足30个正标签训练查询/8个正标签验证查询、测试不足8个查询，或只有一种标签时，不填充或外推。
- token+位置/字段控制、历史CoT token embedding均值+位置/字段控制，与隐藏状态使用相同探针架构。
- query级随机打乱错误分支标签；保持错误出现位置、长度、split和每查询所有token的一致性。
- 相同CoT文本的图结构控制：两类各改一条图边，只有一类使共享候选合法；复用graph_pair和独立semantic_slots审计。扩展三条记录窗口后失去合法性的控制拒收。分别做主探针零样本迁移与单独训练独立MLP探针。
- 探针只读残差，不把错误位置、错误类别或真实状态作为残差特征。

统计AUROC/AP、正负平均概率、BCE/Brier、TPR/FPR，结果按层、字段、首错记录/后1/后2和记录内token偏移分解。
输出概率对应本探针对照数据的采样分布，不自动等于模型自由生成时真实的错误后验概率。
“能解码历史错误”不等于模型有主动纠错策略，更不等于读出方向具有因果作用。
