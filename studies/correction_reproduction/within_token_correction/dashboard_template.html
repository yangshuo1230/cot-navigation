WITHIN-TOKEN CORRECTION / BEFORE EMISSION

当前节点尚未输出：能识错，能在后续层修正吗？

本页已按新问题重做。目标 token x[p] 未输入；读取 h[p−1]。输入前缀合法，合法节点按真实图、visited 和已打印候选集合确定。主终点为实际最终输出层的当前 token 合法率；允许任何合法后继，无固定路径或排序要求。
缺少合法／非法类时保留 NA，不用“总判错”代替识错能力。

1. 输出之前，各层能预测当前选择是否出错吗？

所有探针读取该层 activation；逐层独立参数、训练标准化、验证 BCE 选步。阈值固定0.5。平衡准确率=(已错检出率+合法识别率)/2，同时保留实际类别比例下的准确率与多数类基线。

匹配干净 baseline纠错训练
当前输入 embedding／位置计数与查询级标签打乱对照

2. 临时读出从非法到合法，是否稳定发生？

仅展示仍需输出节点的位置。实线：全词表 argmax 的合法率；虚线：只在节点词表中选最高分节点的合法率。所有曲线终点都与真实最终输出层对照。

中间层读出是诊断代理，不等于模型真的作出了一个离散决定。校准仅读出训练集的冻结最终 logits，不监督正确节点。若浅层读出几乎全非法、校准仍无法恢复有效预测，就不能仅凭“浅层错→末层对”认定存在自我纠错。
逐模型 seed 的读出与合法／非法样本覆盖

3. 固定该层候选倾向，再看后续层能否改变输出

合法／错误均值来自相应探针的自然训练集，最大改动为残差范数20%。真实与随机干预共同回退，直到该层全词表 argmax 和条件节点 argmax 均保持原样；回退到零的样本也保留。所有后续 Transformer 层从同一输入位置重新计算，只取当前输出，不生成后续轨迹。

保持倾向模式下，L6 的实际 token 必然不变，这是约束与结构决定的负对照，不能单独当作“最后一层来不及”的证据。关键是 L4／L5 在候选倾向不变时，操纵错误相关状态是否改变末层合法输出，以及是否超出同范数随机对照。

划分、验证和限制

读出校准训练／验证、探针训练／验证与最终测试的原始查询和图均隔离。自然首错位置额外富集，但输入在错误 token 前截断；主位置集与困难子集分开统计。主因果分析只涉及仍需输出节点的候选字段，列表结束位置不混入节点身份修正。

保持倾向的干预只控制读出 argmax，仍可能改变节点置信度、图信息或其他状态。错误可被探针解码不等于内部存在显式错误检测器。若操纵不足、样本不足或效应区间包含零，不应强行认定该机制是准确率收益的关键。

误差区间为1000次配对查询×模型 bootstrap；先在查询内平均位置，再在模型seed间平均。条件子集可能随模型改变，表中给出可用模型数和查询覆盖。探针样本不足的格子为NA；不补填其他层或模型。
