# 当前节点输出前的识错与层间修正

当前研究问题是：同一个节点尚未输出时，较浅层能否识别当前选择的错误倾向，
并由后续层改变最终节点选择。读取 h[p−1]，预测 x[p]；x[p] 不进入输入。
主终点为实际末层当前 token 是否属于合法下一 token 集合，而不是后续报错操作。

8个冻结 matched_clean/correction latest200k DFS 模型，各4个模型seed，普通N100新图、
可达查询。只使用GPU0；不重新训练导航模型，不写checkpoint/W&B，不保存激活或探针权重。

## 数据与合法性

复用未经编辑的自然轨迹。只取此前语义合法、且尚无显式MISTAKE的前缀；自然首错
位置可作为目标，但在该错误token之前截断。合法集合为真实当前节点的未访问后继，
扣除本记录已输出的候选；允许任意合法顺序。候选已全部列出时，合法输出为分隔符。

每个原始查询按固定随机规则抽取最多4个需节点位置、1个结束列表位置作为主位置集；
额外至多1个自然首错位置作为困难子集。两者分开展示。结束列表位置只用于读出诊断，
不混入主节点身份因果干预。输入前缀按query及字节哈希去重。

官方train的512个query用于读出校准，其余1024个query用于探针；官方val对半用于
各自选步；test独立。全部图与query在这5个用途之间隔离，所有8模型使用相同前缀。

## 两种读出、两个不同探针目标

- 原输出头：每层残差接同一个最终LayerNorm和LMhead。
- 校准读出：各层独立仿射变换，再接冻结输出头；只模仿冻结模型在训练查询上的
  最终logits，2000步、独立验证KL选步，不训练正确节点标签；末层保持恒等。
- 前瞻探针：从各层activation预测本次真实最终当前token是否会非法。各层标签相同，
  在输出之前可用，但不等于判断某个浅层候选是否错误。
- 临时候选探针：判断该层全词表读出实际倾向的节点是否合法。只有当仍需节点、
  读出确为节点时才纳入。某些浅层几乎总读出非法或非节点，合法类不足时保留NA。
  不能用总判错或多数类准确率证明识错。

探针独立训练L3–L6的线性/MLP64头，5000步，逐头验证平衡BCE选步，阈值固定0.5。
报告平衡准确率、实际比例准确率、多数类基线、错误检出/合法识别率、各类样本数。
当前输入embedding+位置计数、查询级标签随机翻转MLP均作对照。不汇报排序面积指标。

早期支持检查发现临时候选读出存在严重单类问题，因此保留该目标并增加明确分开的
前瞻目标；该调整依据训练/验证类别覆盖，不把未来token作为输入或改写正确标签。
初始支持检查文件在results/；当前完整结果在current/results/，正文只使用后者。

## 因果干预

用相应线性探针定义错误预测方向；投影移向自然训练合法/错误类均值，范数上限20%。
按接收样本逐个匹配同范数的正交随机方向。

主模式通过共同回退步长，同时保证真实干预和随机对照不改变该层全词表argmax及
节点条件argmax；回退到0的样本也保留。另保留不约束argmax的干预作对照。既报告
全体需节点位置，也报告非法节点倾向/原本被后续层修正/原本最终会错等预设子集。

后续Transformer层在同一个输入位置继续计算，读取当前实际输出；不生成后续轨迹。
复用原前缀KV，只覆写当前位置后续层KV；该优化经CPU与真实checkpoint完整重放对照。
末层保持argmax干预必然不改当前token，这是结构负对照，不是独立的机制证据。

错误方向可能同时包含图/节点信息；校准读出也不代表模型真的在浅层作离散选择。
需要同时看信号操纵强度、随机对照、读出可靠性和query/model配对不确定性。

## 运行与产物

```bash
.venv/bin/python -m cot_navigation study correction_reproduction/within_token_correction
.venv/bin/python -m cot_navigation study correction_reproduction/within_token_correction_verify
.venv/bin/python -m cot_navigation study correction_reproduction/within_token_correction_report
```

紧凑逐例指标为gzip JSON，current/包含计划、前缀配方、验证和汇总；交互页为
within_token_dashboard.html，正文为REPORT.md。原用户可见的两张旧探针/干预HTML
入口会更新为此实验，旧数据和源码保留用于溯源。

只重建页面可直接运行 `report.py --render-only`。页面默认主要临时候选目标；辅助
前瞻目标的标签由每个接收模型实际输出决定，跨模型错误样本可能不同，不能把其
准确率差单独当作自我纠错机制的因果证据。
