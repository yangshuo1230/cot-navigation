# Natural field/state readouts and logit lens

This separate probe study uses the validated legacy 6-layer cohort: 0% and 30%
error training, seeds 0–3. The withdrawn 6/9-layer rate sweep is excluded.

Run from the repository root:

```bash
CUDA_VISIBLE_DEVICES=0 .venv/bin/python studies/correction_reproduction/state_readouts/run.py
```

Completed model JSON files are reused. The immutable plan prevents accidentally
mixing different sample counts or fitting schedules. `launch.py` starts the same
command detached; check the existing process before starting another copy.

Outputs are under
`outputs/analysis/state_readouts/legacy6_s0123_supplement_20261102/`.
Only compact metrics, source hashes, checkpoint identities and a report are
written. No activation caches or probe/navigation checkpoints are saved.

## Data and split

Reuse unedited natural caches from `natural_history_probes/native`, on positive
queries of main N100 simple DAGs. These are prefix windows that stop after the
first erroneous record plus two more records, not complete natural rollouts.
An explicit MISTAKE, when present, is retained as naturally generated text.

The common training pool contains the first 512 cached queries from each seed-0
donor (0% and 30%); validation uses the first 128 queries per donor. The two donors
share queries within a split. There are 512 distinct training graphs/queries,
128 validation queries, and 256 test queries per receiver. Entire graphs and
queries stay in one split. Each receiver's test text is generated by that same
checkpoint. All receiver models use the same training and validation texts.

Select up to four complete parseable records per sequence using a fixed random
seed independent of model activations and error status. Malformed/incomplete
records cannot supply field labels and are omitted. Long sequences do not
contribute more selected records. Results therefore describe the parseable
natural-record population, not every failed generation.

## Targets

* `field_node`: distinguish frontier / visited / candidates / action, sampling
  one node token from each nonempty field per selected record. Four classes.
* `field_bar`: identify which field a `|` boundary closes. Three classes, with
  identical input token identity across classes.
* State set probes at the third `|`, immediately before the action:
  frontier membership, visited membership, emitted candidate membership,
  true graph successors of the emitted current node, and graph successors
  excluding the emitted visited set. The last two use actual graph edges.
* `successors_pre`: true graph successors at the first `|`, before this record's
  visited and candidate fields are consumed. Current node is the emitted stack
  tail, not an oracle replacement for an earlier incorrect stack.

State targets are sets. Stack ordering is not evaluated. Emitted-state recovery
and oracle-correct search execution are different quantities after an error.
State membership is evaluated over all nodes in the input graph; false positives
are counted. Off-graph vocabulary tokens are outside this set metric.

## Fitting and controls

Freeze the navigation model; fit independent linear and GELU MLP64 probes for
every layer. No parameters are shared across layers. Token-only and token plus
absolute/CoT-position controls use the same optimizer and split. Field labels
are not supplied to these controls. Standardize using only training features.
Train 1,500 AdamW steps, select each layer's best validation loss every 100 steps.
The categorical loss uses inverse training class frequencies. Set BCE uses a
training-only positive weight. Set threshold is fixed at probability 0.5, with
accuracy, balanced accuracy, exact-set accuracy, F1 and confusion counts.
No AUROC is reported.

Raw logit lens applies the frozen final norm and vocabulary head to each layer.
The calibrated lens reuses `within_token.fit_lens`: independent affine maps
trained only to distill final output distributions, without state/correctness
labels. It uses at most 4,096 training and 2,048 validation positions from these
same graph-disjoint splits. Report actual natural next-token accuracy, final
prediction agreement, NLL and KL. The final layer must agree with itself exactly.
This measures stability of the model's eventual prediction; the eventual
prediction itself may be wrong. It is not proof of causal error correction.

### Early-correct calibration extension

`launch.py --early-clean` runs `early_clean_lens.py` in the separate
`early_clean_lens/` output directory. It preserves the original probe results,
mixed-window lens and untouched full test panel. Calibration train/validation
positions must lie in the first four records, with the complete record before
the first semantic error. In addition the receiver's final-layer argmax must
equal the legal natural next token at that position. Thus the retained teacher
predictions are all correct. Identical sequence/token anchors are deduplicated;
up to 4,096 training and 2,048 validation positions are sampled before filtering
receiver mistakes. Exact retained position/query counts are saved per model.

No test correctness is used to fit or select the lens. The original mixed
calibration and this filtered calibration also differ in anchor deduplication,
so their difference does not isolate correctness filtering as a sole cause.

The same runner also reports held-out test strata: all, first-four-records,
whole-record-before-first-error, their intersection, and later correct records.
The original anchor multiplicities are preserved in each stratum. No lens
prediction is used to select test strata. These conditional next-token
accuracies do not estimate full-query navigation accuracy. Parameter fitting
and validation selection are reproduced unchanged before adding these panels;
the original full-panel readouts must match exactly.

### Layer 5 to final semantic legality

`launch.py --legality-transitions` evaluates the same early/correct calibrated
lens and raw lens at layer 5 against the final layer. The consumed prefix must
precede the first semantic error, but the next-token position may be the first
error itself. Whole-record correctness is deliberately not used to select this
test population. A proposed token is checked with shared `correction_replay`,
including an explicit rejection of a fourth separator before an empty action.
Thus any legal candidate/visited ordering is accepted, irrespective of the
actual natural next token. This measures legality of extending a fixed prefix,
not legality of a complete rollout generated from layer 5.

The primary `all_unique_positions` panel combines sampled node positions and
the three field boundaries, without duplicating state anchors. The separate
`candidate_prediction` panel includes the candidate-field entry boundary as
well as sampled candidate-node positions. Both report a paired 2x2 table,
fractions over all positions, and conditional fractions over layer-5 legal or
illegal predictions. Early (first four records) and later positions are split.
Already erroneous prefixes are counted separately as excluded. Per-seed counts,
checkpoint/data identities and reproduced calibration checks are retained.

`verify.py` checks held-out learnability, independent layer coordinates, binary
false-positive penalties and categorical accuracy. The runner additionally
checks graph/query split disjointness, final-layer lens identity, cohort
deprecation guards and checkpoint provenance.
