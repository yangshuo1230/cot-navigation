固定文本：后续动作决策的因果响应

文本固定到动作字段前的最后一个 |；只改所选位置的隐藏状态。已错前缀的应选操作符为 MISTAKE；合法前缀为真实图状态对应的 PUSH／POP／FOUND／EXHAUST。操作符准确率按全词表 argmax 计算。

当干预位置严格早于动作分隔符时，L6 的零效应是模型连接结构决定的：过去位置的最后一层残差没有路径通向后续固定文本位置。它是实现正确性的负对照，不能被解释为“最后一层没有纠错机会”。切换到动作字段前干预，可直接检查 L6 是否改变下一步决策。

不再固定后续文本：完整自由续写

本节固定在首错／匹配 token 干预，强度为 1；不随上方局部位置或强度切换。之后原生 greedy 生成到答案或 4K／STOP 预算。输入图、查询、前缀 token 均不改；不强迫输出 MISTAKE，不拼接参考续写。

口径与可复现性

合法／错误均值钳制只移动一个线性投影坐标，不保证消除全部错误信息，也不是每个个体都单调降低／提高探针概率。每次改动最大为原残差范数的 20%；随机对照按接收样本逐个匹配相同的有符号扰动幅度。错误预测方向也可能同时携带图结构或搜索状态信息，不能直接视为纯粹的错误开关。

首错位置和动作分隔符使用各自的独立探针方向；不跨模型交换 activation。探针训练：自然 train，5000 步、验证 BCE 选步；线性 seed0，独立 MLP64 seed1。配对干预全程 FP32；自然来源文本原为 BF16 生成，不能把这里的 sham 直接等同历史 BF16 评测。

所有导航任务均可达。“合法前缀”指此前没有语义错误，不是不可达图。合法桥接文本到动作分隔符均通过语义检查。合法前缀自由续写可能新犯错，所以 MISTAKE 出现不自动算误报；误报由语义重放判断。

必须同时看随机对照、合法前缀上的损伤、信号操纵检查与真实修复。只有探针概率改变而行为未变，不能说明模型在使用该方向；行为改变若与随机对照相当，也不能归因于特定错误机制。
