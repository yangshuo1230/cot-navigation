# Natural error-signal causal interventions

The active HTML entry now opens the corrected [before-emission current-node study](../within_token_correction/README.md). The material below is the historical post-error/MISTAKE experiment, retained for provenance.

Frozen matched_clean / correction latest-200k DFS models, all four paired model
seeds; ordinary N100 reachable in-context queries. GPU0 only. No navigation
training, checkpoint modification, W&B runs, activation caches or probe weights.

## Direction and controls

Reuse the natural-history corpus, graph/query-disjoint official splits, matched
natural readouts, frozen model adapter and independent position probe fitting.
Refit a linear probe (seed0) and an independent MLP64 readout (seed1), 5000 updates,
validation BCE selection, separately at first-error onset and action-boundary
positions. Only residuals after L4/L5/L6 are included. Classification accuracy
always uses probability threshold 0.5. No direction is selected on test effects.

For each model/site/layer, convert the standardized linear weight to a unit
direction in raw residual coordinates. Move its scalar projection toward the
legal or erroneous **probe-training class mean**; doses 0.5/1 for local readouts,
dose1 for free continuation. Every displacement is capped at 20% of the recipient
residual norm. This controls one error-predictive coordinate; it does not claim
to erase all nonlinear error information. Independently trained MLP changes
are recorded as a manipulation check.

Controls: unchanged state, unit random direction orthogonal to the learned axis,
with exactly the same signed displacement norm per recipient, and natural legal
prefixes. All directions, means, caps, doses and sites are fixed before testing.
There is no direct activation transfer across different models.

## Two distinct endpoints

1. **Fixed-text local decision:** patch onset or the last `|` before the action;
   preserve every input token through that action separator. Measure the raw
   next-token MISTAKE probability, desired-operator accuracy, KL and changes in
   both probes. A last-layer patch at a strictly earlier position MUST have zero
   effect here; this is a structural negative control, not evidence that the
   final layer cannot initiate a correction. The action-boundary experiment
   explicitly tests the final layer's immediate decision influence.
2. **Free continuation from onset:** consume the unchanged natural prefix only
   through the error/onset-matched token; patch once during prefill. Higher-layer
   KV is rebuilt, hooks removed, then greedy cached generation uses the original
   context/STOP budget without reference continuation, oracle answer or imposed
   correction. Reuse correction_replay to measure action-level MISTAKE, false
   marking, actual first-error repair, effective trace validity and final answer.

Both branches are FP32; natural source texts were originally BF16 generated.
Effects compare paired FP32 counterfactuals, not historical BF16 outcome records.
All task queries remain reachable; a probe-negative prefix is not a negative
navigation query. Final-answer accuracy is conditional on these selected
prefixes and does not directly measure overall free-generation training gains.

## Test cohort and output

Select at most128 natural candidate-first-error query pairs common to both sites,
without probe-score/output-based selection; the first32 seeded pairs supply the
free-generation experiment. Negative local bridges must stay semantically legal
through the action separator. Positive and negative prefixes remain unedited.
All8 models use the same selected prefixes. Actual cohort counts are saved in
selection.json and per-metric reports; multiple seeds do not create more graphs.

`run.py` saves only compact scalar per-case local/free results, the six small
directions/targets per model, source identities and at most eight trace excerpts.
Native continuation may stop at budget; that flag is reported rather than being
counted as a correct answer. Results are paired to the same prefix's unchanged
continuation. Random-control-adjusted differences and query/model uncertainty
must accompany any mechanistic conclusion.

The shared natural prefixes need not be generated by the receiving model.
Single-position interventions also allow later tokens/layers to recompute the
same error information. A weak free-continuation effect cannot establish that
all error information is unnecessary; an effective direction may also encode
graph/search-state information rather than a pure binary error flag.
