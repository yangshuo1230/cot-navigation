# hard_dag_v1_s0 训练结果检查（2026-10-22）

只读取已有配置、验证日志、测试报告和预测记录，没有启动训练或补跑已取消的评估。

## 范围和口径

- 本批 17 个任务分支：新图 5 个，固定图 N36 和 N100 各 6 个；另有两个共享知识阶段。
- 模型均为 6 层、1 头、d_model=128、d_ff=512，标准 FFN、RoPE、上下文上限 32768。
- 新图训练 200k 步；固定图 N36 任务训练 75k 步、N100 训练 125k 步。
- 新图按验证 accuracy 选 best，且只在 step≥150k 时有资格入选；固定图按 balanced accuracy 选 best。last 为最终权重，不能依据测试成绩改选 best。
- 新图每组测试 256 查询（128 正、128 负）；固定图 N36 为完整测试集合 63 查询（42 正、21 负），N100 为 256 查询（135 正、121 负）。
- 数据为 multiscale_dag_v1 非严格分层 DAG；配置中的层数/宽度描述生成器的拓扑秩分带参数，distance 不能直接解释成最短路径跳数。
- 本批仅模型 seed 0、固定图 graph seed 0；不是三 seed 的重复实验。本批没有 Filler，也没有新图 Direct 对照。

## 训练过程与初步判断

- 新图 DFS state 在 45k 的小图验证为 82.81%，50k 切到更大图时降至 50.00%，95k 回升至 85.94%；100k 再切规模时降至 65.63%。这些点的验证图分布改变，不能当作同一集合上的遗忘。
- 新图 DFS state 在最后 N100 阶段：150k 为 79.69%，165k 为 85.94%，200k 为 84.38%，没有呈现继续增加步数就持续改善的趋势。
- 固定图 N100 多数 best 出现在 10k–60k，而非最终 125k；更长训练并未在本次运行中持续改善泛化。
- 固定图上，Path、DFS nodes 已经达到 255/256；完整状态输出没有显示一致优势。新图上，完整 DFS state 相比节点序列更有优势，值得优先研究。
- 现有结果支持“不同 CoT 协议的效果取决于知识是否在参数中”；不支持直接断言“CoT 优于不使用 CoT”，因为新图 Direct/Filler 对照缺失，固定图又只有一个图 seed。
- 判断训练不足或容量不足仍需要独立实验。当前证据更明确地暴露了自主生成与正确前缀条件下表现的落差，以及 checkpoint 选择的波动。

完整原始指标汇总在 summary.json。所有测试均来自优化前已经保存的结果，没有混入新的加速基准或重跑结果。
