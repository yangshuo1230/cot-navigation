# 扩大合法 activation-patch 配对数据

目的：减少上一轮每字段2–4对造成的偶然性，主动构造同 token、不同上下文的合法例子。默认每模型 × 两类配对 × 三字段 × 128对，目标3072对。模型仍为原四个 N=100 完整状态 checkpoint，不重新训练。

## 两类配对严格分开

### exact_field：一个字段完全相同，另外两个字段语义不同

新图从 train/val/test 中抽取基础图，并随机改变合法邻居优先级。对另一基础图的 donor 施加**单射节点重命名**：把待匹配字段中的节点逐一映射到 recipient 对应节点，然后将剩余节点一一映射到 recipient 剩余节点 ID。两图使用相同的节点词汇集合，目标字段逐 token 一致，其他字段分别要求有序 frontier 不同、visited/candidates 集合不同。

重命名同时作用于边列表、查询起终点和整条搜索轨迹。没有修改一处 token 而保留不一致图/状态的做法。原图结构不变，搜索行为对节点重命名等变。visited 匹配需要合法但不同的 frontier 历史；无法满足的初始状态不伪造。

固定图禁止此类重命名。模型只看 WORLD 和查询，没有新边列表，任意置换名称会改变其已学节点含义。固定图在原 WORLD 上构造额外起终点组合和随机合法邻居优先级，用实际合法轨迹进行原生精确字段配对。未找到足够配对的格子如实保留不足，不用重命名冒充已知图。

固定图 BFS 的 frontier 格是结构性缺格：当前图只连接相邻层，当前节点的已发现后继还没有出队，因此 `CAND = successors(queue[0]) - set(queue)`。相同固定图、相同有序队列必然给出相同候选集合，不可能同时要求候选集合不同。独立重放审计也逐例验证此关系。新图可以改变邻接关系，不受这个限制。

### shared_history：整段 CoT 历史相同，正确后续不同

新图：保留截至当前整条记录为止出现的全部节点名称，也固定查询起终点名称；只对其余节点做无固定点的循环置换，同步修改输入图及后续轨迹。要求下一记录的参考状态或动作确实不同。因此两边**CoT 前缀逐 token 相同、长度相同、查询名称相同**，差异在输入边列表及未来节点名称。图的节点词汇集合也相同。绝不是整个输入相同而要求确定性任务产生两个答案。

固定图：保留原图和整段 CoT 前缀，把查询目标换成下一条记录的当前节点。拒绝此前已经作为当前节点展开过的目标，保证 donor 不会提前终止。下一记录因此合法地 FOUND，而 recipient 的下一动作不同。图没有任何改名，查询 token 不同。BFS 常需选 POP 之后，DFS 常需选 PUSH 之后。

shared_history 的当前整条记录完全相同；在字段后立即续写当前记录时，两边的正确输出也应相同，是控制组。下一记录才是有不同正确后续的主要读取。不能把这类配对说成“另外两个当前字段不同”。

## 数据量与分层

默认1800个候选基础图/查询，每个生成3种邻居优先级。新图来源包含 train/val/test；固定图从原图上全部前向节点对中抽取查询，不限原测试集。这里是机制诊断数据，混合来源上的正确率不是测试集泛化准确率。

每类配对、每字段目标128对，按 visited 大小分为1–3、4–7、8–15、16及以上四档，尽量均衡。该指标是**搜索历史大小**，不是输入图的层数或栈深度。每格尽量使用不同基础图/起终点查询，多个命名变体共享基础图 unit，统计时不当成独立新图。

每个生成轨迹先由参考搜索构造，再由独立状态机从图邻接关系逐记录重放：检查 frontier、visited、精确候选集合、动作优先级、PUSH边、POP位置和终止标签。所有改名保持节点唯一、词汇合法、图/query/trace一致。前缀最长3000 token，给下一完整记录留下足够上下文。

最终数据只保存可复现 recipe：基础图索引、source/target、邻居种子、节点映射、记录序号、前缀哈希。不保存大批完整轨迹、激活或 KV。默认生成后压缩保存，每模型一个数据文件。

## 干预和指标

复用前轮因果实现：在 post-block residual 替换当前记录的节点、字段末尾 `|`、PUSH/POP 操作符或 `;`，以及节点+分隔符、全部组合。PUSH 参数不干预。替换后重新计算后续层 KV，hook 只在 prefill 生效。

L2/L4全量；L6与self-patch稀疏抽样作检查，不为重复结构负对照消耗大部分计算。每个干预都有同 batch 未干预 twin。无历史 donor 与构造 donor 均测试。操作符 token 不同的配对仍用于其他组，跳过操作符及含它的组合。组合比较取共同 case 集。

同时生成未干预 recipient 与 donor 控制记录，确认两边模型是否能完成对应的合法状态。区分：记录变化、真正动作变化、字段变化、未完成/格式失败、recipient 合法动作、是否向 donor 特定字段/动作迁移。仅在两边模型控制都能正确预测、参考后续确实不同的样本上，统计强方向性迁移；不能把破坏输出当成传递信息。

按基础图/原查询聚类统计，报告不同历史档的结果；不把同一基础图的命名变体或各层/位置重复干预当独立样本。固定图结论仍条件于 seed0，不能外推为多图 seed 显著性。

没有导航模型训练、RL、W&B run或新 checkpoint。只保留压缩配对数据、每模型/读取的压缩统计、少量关键例子和关键结果图。
