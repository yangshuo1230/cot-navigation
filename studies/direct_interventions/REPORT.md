# Direct 成对干预检查：2026-10-18

使用两个现有 10k latest checkpoint，仅推理，无优化器、无训练。主结果为 FP32，关闭 TF32。
分别取 512 个训练图 anchor、512 个未见图查询，每组正负各半；所有模型共用输入。
该子集、边顺序与上次正式测试不同，准确率不应直接与此前 1024 例测试作差。

## 设计与检查

- 固定图与 source，换 target，使标签翻转；另有只换 source 的对称检查。
- 查询变更限定同层候选，避免把非法层间查询引入测试；新 target 至少有入边，新 source 至少有出边。
- 关键边：对同一相邻层的两条边作 2×2 交换，翻转查询答案。
  例如 (s,t),(u,v) -> (s,v),(u,t)，新边要求原来不存在。
  保持 N16/M24、全部节点、逐节点入度/出度、全部 token 计数、长度及 query 不变，仅两个终点 token 交换。
- 无关边：相同的 2×2 操作，避免触及查询两端，保持答案不变。
- 边顺序：每个原图另外重排四次；不改图和 query。
- 额外检查相同标签的 source/target 替换，区分语义变化与仅改变名字的效应。
- 每个变体均通过独立遍历 oracle 与 bitset oracle，并核验一跳边存在性。
- 不满足干预约束的样本不强行编辑，因此各检查 n 不同；关键边 train n=325，new_graph n=306。
- 检查前后 checkpoint SHA256 一致，训练文件没有修改。

概率指标使用 P(YES | YES或NO)，同时保存完整词表 raw P(YES) 与有效答案概率质量。
所有表格中的概率变化为 0–1 概率单位；不是百分点。

## 多 query 模型

- train: P(YES) 均值 0.5047764182，标准差 1.36e-07，范围 [0.5047760009765625, 0.5047767758369446]；全部输出 YES。
- new_graph: P(YES) 均值 0.5047764248，标准差 1.42e-07，范围 [0.5047760009765625, 0.5047768950462341]；全部输出 YES。

关键边、无关边、source、target 与顺序干预，平均绝对概率变化约 5e-8 到 1.3e-7，均未改变答案。这与 FP32 批处理数值变化量级接近，不应解释成有效语义信号。
当前读出表现为近似常量预测器。每图正负各半使图本身不能稳定提供标签，而查询匹配规则尚未形成，是一个与结果相容的学习失败解释；未证明训练动态因果。
