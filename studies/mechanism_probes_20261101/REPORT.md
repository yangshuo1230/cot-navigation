# 四个机制假设的 probing 与干预复查

2026-11-01，同一冻结185k In Context DFS-state模型，CPU FP32，没有训练模型。本轮复用N100的18条val与18条test查询；不是新增36次自由生成。主实验是正确参考前缀下的机制诊断。

## 结论强度

1. **支持“当前显式visited列表不是本轮候选过滤的主要直接输入”**：基线正确、且编辑后集合应变化的100个条件里，候选输出均未改变。不能扩展成“访问历史从未被使用”。
2. **支持回访沿历史候选进度/上次PUSH载体续写**：344个回访记录的候选集合恰为旧列表去掉上次PUSH节点。屏蔽L5旧PUSH/参数value使16个候选字段全部失败；只是改参数字面token却没有改变输出，因此载体上下文与字面节点身份必须区分。
3. **支持stack长度信息可线性读出，不足以证明长度方向控制终止**：L4目标长度测试R²=0.954，剩余数量R²=0.941；定向干预增减1或2均未切换停止/继续。
4. **不支持把L1通读历史`|`直接解释成读取已有字段标签**：L1所有同字面`|`的V精确相同；字段身份在L1仅49.7% query-balanced准确率，L2为93.6%、L3为98.7%、L4为100%。
5. **L5常已有输出内容信息，但L6仍承担真实计算**：许多节点/动作能由另训线性decoder从L5读出；L6 FFN对固定输出头的正确读出很重要，L6 attention尤其影响字段结束。

## 1. 候选过滤：当前visited、全局访问历史与旧PUSH不是同一件事

在18条test查询中，每条按fresh/revisit及跨分支过滤与否选择接近轨迹中部的状态，共60个候选字段。给正确前缀到本轮visited结束符，让模型自行生成整个候选字段，最多12个token，要求节点集合正确、无重复并以`|`结束。60个基线中59个正确。

编辑保持当前visited长度与所有分隔符位置不变，历史、图、stack不变。它们可能与旧DFS历史矛盾，故是“显式字段是否被使用”的诊断，不是合法替代搜索。下表仅保留基线正确且编辑后候选集合应该改变的条件。

| 当前visited编辑 | 条件数 | 实际候选输出改变 |
| --- | ---: | ---: |
| 全部节点改成起点 | 42（17条query） | 0 |
| 移除一个跨分支已访问邻居的显式出现 | 25（13条query） | 0 |
| 把一个本应可选的邻居加入visited | 33（17条query） | 0 |

100个条件不是100条独立查询，三种编辑会作用于同一状态。直接改当前visited的身份几乎没有使模型重新执行集合差，支持用户提出的显式字段冗余解释。模型在首次到达某节点时仍能过滤其他分支访问的邻居，说明全局访问信息可能保存在别的历史载体中，不能据此宣布visited语义本身消失。

参考轨迹中344个回访记录全部满足：本轮候选集合=上次同节点候选集合−上次PUSH节点。本数据图族下，这种续写规则足以解释这些记录的集合；344条记录来自18条查询，且这种集合关系本身由合法DFS/图结构约束，不是模型使用了它的单独证明。

因此又做了L5局部value干预：固定初始接收位置的Q/K与权重，只改旧PUSH或其参数位置向候选预测位置提供的value贡献。生成整个字段时保持同一接收位置的干预。16个状态各来自不同query，基线全部正确。

| 条件 | 整字段集合正确 |
| --- | ---: |
| 原始基线 | 16/16 |
| 屏蔽旧PUSH位置value贡献 | 14/16 |
| 屏蔽旧参数位置value贡献 | 3/16 |
| 屏蔽两者 | 0/16 |
| 参数同幅度随机扰动 | 9/16 |
| 两位置同幅度随机扰动 | 9/16 |
| 旧参数value换成旧候选列表中同一字面节点的value | 3/16 |

这些状态中L5在旧PUSH位置的平均attention为16.0%，旧参数位置为74.5%。参数位置更主要，但14个另选的回访状态中，只修改历史PUSH参数的字面节点，候选输出0/14改变。二者并不矛盾：L5读的是经过L1–L4处理后的上下文表示，不能把它等同于参数token的原始字母。

目前支持“历史候选进度载体”，还没有证明它精确实现了按节点身份删除。可能是旧列表后缀、位置指针或其他等效表示。随机扰动并非完全无效，需保留其9/16正确的对照，不能把所有破坏都解释成语义特异性。

## 2. stack是否长度控制

采样4334个stack节点位置，记录目标长度d、已输出数量j、剩余数量d−j。训练/开发/测试按整条query划分：val的12条训练、6条开发选择ridge正则强度，随后在18条val重拟合，18条test只作评估。同一query的token不会跨训练测试。已有test panel此前曾用于其他分析，因此是probe拟合层面的holdout，不是全新的未见研究样本。

| 表示 | 目标长度R² | 已输出R² | 剩余数量R² |
| --- | ---: | ---: | ---: |
| 位置控制 | .317 | .991 | .113 |
| L0 | −.420 | −.469 | −.114 |
| L1 | −.405 | −.031 | −.122 |
| L2 | .856 | .964 | .802 |
| L3 | .866 | .989 | .796 |
| L4 | **.954** | .986 | **.941** |
| L5 | .936 | .977 | .922 |
| L6 | .876 | .953 | .865 |

位置控制输入包括绝对位置、记录起始位置、记录编号与已输出数量j，因此j的高分是控制设计本身，不是发现。L4目标长度RMSE约0.491，四舍五入完全正确率67.7%；剩余数量RMSE约0.489，完全正确率72.4%。高R²不能写成每个位置都有精确整数寄存器。

再按开发集目标长度R²在L1–L5中选择L4。使用val拟合的probe系数构造方向，使目标长度解码值±1、已输出解码值不变；在6条long test查询的stack末节点和倒数第二节点各一个位置做干预，另做±2剂量、等范数且对两个probe均为零的随机方向、sham。所有基线正确，接收位置之前logits精确不变。

±1与±2两种剂量，各自的12个位置均没有切换停止/继续；随机方向也没有切换。±1扰动约为该位置残差范数的2.7%–2.8%。部分停止margin沿预期方向变化，但没有形成输出类别切换。**因此长度信息可读，但这个线性方向尚未证明是实际停止控制器。** 也不能以阴性结果排除非线性编码、冗余或对多个位置协同的依赖。

## 3. `|`的L1是否在确认字段身份

对4491个字段结束符，探测其为本记录第一个stack-bar、第二个visited-bar或第三个candidate-bar。不是预测下一个节点身份。相同query划分与ridge选择规则。

| 表示 | 测试query-balanced准确率 |
| --- | ---: |
| 位置/到前一bar距离/记录编号控制 | 64.8% |
| L0 | 33.3% |
| L1 | 49.7%（token-pooled balanced accuracy为51.9%） |
| L2 | 93.6% |
| L3 | 98.7% |
| L4–L6 | 100% |

L1读取此前bars的query-balanced平均attention，三种bar分别为54.8%、60.7%、61.6%，确实存在广泛读取。

但该模型没有加到embedding上的绝对位置向量，位置由attention中的RoPE处理。在L1的V投影之前，同字面的所有`|`只有相同embedding和LayerNorm；实测它们的V向量差精确为0。因此**L1不能经由V搬运前文不同`|`已经带有的字段语义标签**。它仍可借助相对位置导致的Q/K权重、bar总质量和其他token的组合建立格式特征；不能把这一限制扩展成L1没有作用。

6条long test×三种bar的18个局部条件中：同字面bar的value互换18/18精确不变；把历史bar value贡献置零，最终下一token改变2/18；同范数随机扰动改变1/18；去掉接收位置全部L1 attention改变9/18。L1 probe类别也会被不特异的随机扰动改变，所以不能靠probe变化宣称已定位“字段身份电路”。目前更合理的层次描述是L1提供格式/位置相关特征，L2–L3以后字段身份稳定可读，但它怎样被下游功能性使用仍需定向验证。

## 4. L5已有信息，L6还做什么

区分三件事：直接把L5接最终LayerNorm/固定输出头（raw logit lens）；在val上另训线性decoder从L5预测最终logits（校准读出）；真实删除L6 attention或FFN后的网络输出。校准读出不修改原模型，也不是额外训练过的搜索模型。

L6 attention删除时重新计算其后FFN：`x5 + FFN6(norm2(x5))`。FFN删除时保留真实attention输出：`x5 + attention6`。因为这是最后一层且FFN逐位置计算，这些结果也对应选定位置上的组件消融。下表所有比例均为test中先按query内平均、再跨query平均的**与原最终token一致率**，不是DFS语义正确率；候选存在合法多种顺序，不以canonical一致率代替语义准确率。

| 事件 | 原输出头直接读L5 | 校准decoder读L5 | 去掉L6 attention | 去掉L6 FFN |
| --- | ---: | ---: | ---: | ---: |
| PUSH后stack初始化 | 6.8% | 100% | 100% | 7.7% |
| POP后stack初始化 | 14.4% | 100% | 100% | 15.7% |
| stack续写 | 82.9% | 97.7% | 100% | 80.6% |
| stack结束 | 41.7% | 64.8% | 27.8% | 88.9% |
| visited初始化 | 72.7% | 100% | 100% | 75.0% |
| visited续写 | 56.9% | 85.2% | 93.5% | 61.1% |
| visited结束 | 93.1% | 97.2% | 94.4% | 100% |
| 回访候选首项 | 19.5% | 95.9% | 95.4% | 5.3% |
| 候选结束 | 92.4% | 75.4% | 38.0% | 100% |
| 判断POP | 24.3% | 100% | 100% | 26.2% |
| 判断PUSH | 53.0% | 100% | 100% | 54.4% |
| PUSH参数 | 97.7% | 100% | 100% | 90.2% |
| 记录分号 | 38.0% | 74.1% | 95.8% | 38.0% |

因此，用户的“L5大部分已经确定”对于若干节点内容/动作的**可读性**很有依据，但与“不需要L6”不同。L6 FFN把L5已整合信息转成固定输出头能正确读取的形式，在初始化、回访候选与动作上作用突出。L6 attention对于stack/candidates的结束位置很重要，不能概括成纯粹格式美化或信心增强。

全局线性decoder不是可读性的上限：少数阶段的校准分数比原lens低，可能源于全局拟合、样本覆盖或表达能力；不能把它当成信息不存在。消融也不能定位具体Q/K比较算法。此前“换某个FFN输出能改变结束”只是充分性诊断，本轮真实去掉FFN时部分结束事件仍保持100%，两者并不矛盾。

## 复现与限制

`collect.py`收集36条参考查询表示与组件；`probe.py`做query分离的线性probe；`length_intervention.py`做验证集选层的长度方向干预；`candidate_tests.py`生成完整候选字段并编辑当前visited/旧参数；`push_carrier.py`做历史PUSH/参数的局部value干预；`layer_bar_tests.py`做最终层真实消融、分隔符同V检查和L1干预；`readout_probe.py`拟合校准读出；`summarize.py`检查结果并生成汇总/曲线。全部原始条件、阴性与错误保留，见同名JSON。

试验仍依赖正确参考前缀；非法显式字段编辑不是合法替代搜索。多数定向干预只有6或16条查询。正结果支持局部功能依赖，负结果不证明不存在冗余线路或非线性编码。本轮没有把完整历史中的所有visited位置全局移除，因此只能削弱“当前显式列表直接过滤”，不能证明visited字段在所有后续计算中无用。
