# NO偏向：两项诊断的结果

已完成17个冻结checkpoint、39个条件、3816个模型—查询配对。固定图/新图各包含五种CoT和Direct基线，另含五组DFS loss/SWA模型；新图还测深窄N100与N144。旧规模课程使用验证best，loss/SWA使用最终checkpoint。没有训练或修改权重。完整性检查另外核对2312条完整状态动作序列。

完整状态和SWA的正确参考负例也全部回答正确。DFS节点版参考负例为94.44%，其他上述节点/Path负例为100%。这支持许多自由生成错误发生在得到正确搜索结果之前，而非仅在最后答案位置无法输出YES。十个新图CoT checkpoint的主规模面板共出现96次“真实可达但自由生成答NO”的模型—查询对，这些输出中均没有把目标作为当前/展开节点或路径节点输出，也没有FOUND。

重要限制：完整状态参考显式包含FOUND/EXHAUST，当然是强答案线索。此诊断只能说明给出正确过程和终止线索后能否读取答案，不能证明模型独立计算了可达性，也不能单独排除答案token的任何偏置。

## 负例答对时，是否真的完成了合法搜索？

以下分母是全部自由生成答对的真实负例；动作回放忽略打印出来的frontier/visited/candidates，严格依据图及真实动作历史，避免把单纯注释错误当成动作错误。

|新图N100模型|答对负例n|其中动作不完整或非法|
|---|---:|---:|
|DFS完整状态|33|11 / 33 = 33.33%|
|BFS完整状态|36|13 / 36 = 36.11%|
|DFS节点版|35|15 / 35 = 42.86%|
|BFS节点版|33|17 / 33 = 51.52%|
|DFS全历史 λ1|35|11 / 35 = 31.43%|
|DFS全历史 λ4|35|10 / 35 = 28.57%|
|DFS全历史 λ16|35|10 / 35 = 28.57%|
|SWA最近1条|34|13 / 34 = 38.24%|
|SWA最近2条|36|13 / 36 = 36.11%|

例如DFS完整状态的11个错误动作序列，首个动作错误均为非边PUSH；SWA1的13个错误序列中，6个仍有未访问邻居就POP、6个非边PUSH、1个重复PUSH。SWA2分别为3个有邻居就POP、9个非边PUSH、1个重复PUSH。SWA1、SWA2和BFS完整状态主规模的答对负例没有STOP；其余完整状态模型有少量STOP，已单列。因此不能把全部过程错误归结为上下文截断。

固定图也有类似现象，动作错误比例分别为DFS完整状态34.38%、BFS完整状态13.79%、DFS节点版26.67%、BFS节点版19.35%。不是所有固定图问题都能用搜索失败解释：固定图BFS节点版的4个正例误答NO时，目标已经出现在输出中；给参考轨迹后正例召回仍只有90.62%。

Path负例只承诺从起点出发的合法随机路径，不承诺穷尽图；一条走到sink的路径不能证明不可达，所以其“不可达证明完整性”不适用。Direct没有外显过程，不能用该方法检查，也不向它强塞未训练的CoT。

## 长度泛化的例外

DFS节点版在N144上，正确参考轨迹下的全词表答案准确率只有53.41%，其中42.05%首选token不是YES/NO；仅比较YES/NO分数时准确率为84.09%。因此，长度泛化下还存在何时结束节点序列并输出答案的问题，不能把所有NO相关错误都解释为搜索漏检。

## 结论与适用范围

两项诊断共同支持：许多模型更容易在生成过程中丢失可达证据，而同类不完整或非法计算在负例上仍能得到正确NO。负例答案准确率因此不能作为完成不可达证明的证据。它们没有证明这一解释是唯一原因，也没有证明每个模型、每种规模都具有相同的NO偏向。

这是每个TEST层差×标签最多4条的小面板，不等同此前256条/条件的原生测试。参考轨迹过长的查询单列并从完整oracle配对中排除；完整状态注释检查与只回放动作分开统计。全部逐条件数值、样本数及STOP分解见[完整报告](REPORT.md)，[CSV](summary.csv)，[语义与完整性验证](verification.json)。
