# 工作记录

本轮要求：在下一个 token 尚未生成时，通过最后已输入 token 的深层状态判断这个已输入 token 是否错误；增加人工训练数据，并使用 MLP。

- 读出约定固定为 `h[layer,t-1]`，输入截止 `x[t-1]`。不输入 `x[t]`，不附加 dummy token，不再使用旧分析的 +1 读出。
- 复用原验证集选出的模型，15 个适用 checkpoint（新图 3 个、固定图 9 个、固定图 BFS-state 对照 3 个），固定图保留三个 seed。
- 人工数据目标：训练 8192 对、验证 2048 对、测试 4096 对；一个 pair 是一个错误前缀和一个合法前缀。训练只使用人工数据，真实首次错误完全留作外部测试。
- 改写共享合法历史，只有最后一个 token 不同。图内错误节点、过早分隔符、额外节点、错误动作分别记录；Path 训练只含图内节点错误。合法候选多解时随机选取。
- 原查询 split 不变；固定图多改写共享查询。按查询逆样本数加权，避免长轨迹/大量改写主导训练。
- Linear 与 64 hidden GELU MLP 对照，均跑三个初始化；L4/L5/L6 各自独立训练，加相同架构的 embedding/位置/字段对照。AdamW、1000 更新、人工验证集 BCE 选最优状态。
- 使用物理 GPU0；导航权重冻结。旧实验、旧结果、旧 checkpoint 均不修改。没有保存探针 checkpoint、activation 或新增 W&B run。
- 新增 4 个测试与既有 23 个分析测试一起通过。测试验证合法/非法前缀标签、多改写唯一性、确定性采样、读出无未来 token、独立非线性头。
- 结果保留人工/自然分布、错误类型、字段、层深度与正负概率的细分；自然样本很少的设置只作诊断。不同初始化的方差不是测试样本置信区间。

最终数值、因果掩码验证与 checkpoint 哈希验证见 `results/REPORT.md` 和 `results/verification.json`。
