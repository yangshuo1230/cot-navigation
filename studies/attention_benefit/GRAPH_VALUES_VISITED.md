# 图内上下文 value 与 visited 读取补查

2026-10-24，全部完成。GPU0，冻结原 N100 简单分层图 DFS clean λ16 / 错误数据30% λ16 last200k。相同256个查询、877个正确轨迹候选预测状态，其中非空487个、存在已访问出邻居399个。没有训练、checkpoint、W&B run 或 activation dump。

## 用户所指的通路

用户指的是图内节点本身可汇集此前边信息，再被后层读取；不是仅指 CoT 中的当前节点中转。此前恢复 CoT token 的实验没有直接回答这条通路。

因果模型中，图内位置可以汇集前方信息，不能读取后面的 token。特别是 `<EDGE>` 在自己的起点/终点之前，它不能直接在输入表示阶段看到其后尚未到达的两个节点；深层该位置仍只能编码此前位置。

## 已有 attention 的明确事实

以下取非空候选的预测位置，沿用 main.json，均为 query macro 平均原始 attention：

|层|baseline 输入节点位置总质量|baseline 当前 visited 节点质量|错误训练模型当前 visited 节点质量|
|---|---:|---:|---:|
|1|1.30%|6.06%|16.46%|
|2|6.07%|0.80%|89.03%|
|3|6.08%|9.59%|3.90%|
|4|0.57%|56.41%|1.80%|
|5|4.28%|3.19%|0.27%|
|6|0.01%|12.73%|0.29%|

这里的 visited 包含当前记录 visited 字段内节点，不含两侧分隔符。错误训练模型 L2 的当前节点 CoT 总质量为62.36%，但该数覆盖所有CoT出现位置，不能和89.03%直接相减作为 visited 其他节点质量。

baseline L5 非空状态读图总质量29.16%，其中图节点4.28%、EDGE标记24.88%。另在混合空/非空的877个状态中，每个状态取最强图内 key，再按查询平均，96.81%为EDGE标记、3.19%为起点节点、0%为终点节点。这不是“所有层都只关注EDGE”的结论。

## 保持 Q/K/attention 不变，替换图内 V

新增 graph_values_visited.py 和 graph_value_roles.py。只编辑 L5 候选预测位置的 attention 输出，不影响其他查询位置的 attention 输出。

1. 对同一模型、同一输入，在前4层限制图内每个 query 只能读自己；query和CoT的位置仍按正常因果规则计算。
2. 由该前向获取 L5 图内 V。因图内 token 从未读其他位置，其 V 不含周围边上下文。所有图内相同 token 的 donor V 完全一致，实测最大差0。
3. 在正常前向的候选预测行，保留原始 Q、K、RoPE、softmax 权重；仅替换选定图内 key 的 V。
4. 所有比较包括 identity 均使用相同的选定行 FP32 math 路径。和原SDPA少量BF16 argmax差异分别为L5 clean/error各2/877，L2 clean4/877、error1/877；因此结果采用各自同路径identity作比较。

N100 非空候选，指标为下一token属于任意合法候选的比例，先按查询平均：

|L5图内value干预|baseline|错误训练模型|
|---|---:|---:|
|identity|96.07%|97.90%|
|最强3个图内key换为无上下文V|92.48%|32.05%|
|3个角色相同、位置接近的其他图内key换V|96.07%|97.74%|
|全部图内key换为无上下文V|88.20%|31.62%|
|最强3个图内key的V置零，attention不变|94.00%|36.41%|
|只替换EDGE标记V|89.68%|未运行|
|只替换图内节点V|96.07%|未运行|

这些结果支持 baseline 图内被读取位置的上下文 V 有功能，特别是EDGE标记位置。不能据此确定 V 编码的是哪条邻接关系，或确定所有功能只经这些位置传递。替换 donor V 同时改变其方向、幅值等上下文相关属性，不能当作专门删除一个语义特征。匹配位置也不严格匹配attention质量。

对图内节点V的局部替换未降低L5该指标，不代表节点无作用：它们可能在更早层发挥作用，也可能通过 K 影响寻址，而本实验固定原始 K。之前只遮蔽某条原始边的三个token，也无法抹掉已扩散到其他位置的信息。

## 纠错模型确实读取并依赖 visited

只在第2层候选预测位置，屏蔽当前记录visited字段内指定节点key并重归一化，其他层和历史表征均保持正常：

|错误训练模型 L2干预|非空候选合法率|
|---|---:|
|该层identity|97.90%|
|屏蔽整个visited字段节点|26.87%|
|只屏蔽visited中等于当前节点的token|32.63%|
|只屏蔽visited中其他节点|92.80%|

在399个“当前节点存在已访问出邻居”的状态中，屏蔽其他visited节点时合法率98.80%→89.36%。这与visited帮助候选生成相符，但这个干预并未专门区分身份定位和集合排除的所有计算步骤，不能据此宣布完整实现visited过滤算法。

baseline第2层visited屏蔽几乎无效，只说明它不是在同一层使用该通路。它第4层有56.41%的attention在visited，之前历史节点恢复也有功能；未在本补查中对baseline第4层逐字段做对应消融。

## 更新后的解释

两个模型都可能结合图内信息汇集和CoT状态读取。错误训练模型表现为候选位置L2强读visited、L5强读相关边终点；baseline更依赖不同层的visited/历史表征，且读取图内上下文化位置，包括EDGE标记。仅看“对原始相关边节点的attention”会漏掉图内的信息传播，也会漏掉visited读取。

尚未完整重建边→图内位置→visited/CoT→候选的电路；尚不能把局部候选收益等同于最终答案收益，或将训练差异唯一归因于错误监督。本结果只覆盖当前简单图DFS模型。
