# 边列表屏蔽复核：baseline 的信息汇集与历史表征恢复

2026-10-24。全部实验已完成，只用 GPU0，无训练、checkpoint 或 W&B run。

## 结论修正

baseline 同样依赖图，而且在候选预测时高度关注少数 CoT token。之前屏蔽的是候选预测位置的直接读图，并未阻止历史 token 先读图、再被候选位置读取。把该实验描述成“关闭边列表”不够准确。扩大到所有非图位置后，baseline 明显退化；历史节点的 activation 恢复实验进一步支持了间接传递图信息的解释。

两模型确实有不同的通路依赖，但尚未重建完整电路，不能把最终答案提升归结为 attention 总量增加。

## 数据与指标

- 同一对 DFS checkpoint：clean λ16 和错误数据 30% λ16，均为 last200k；冻结模型。
- 简单分层 DAG 家族：N16 和 N100，每个规模同一批 256 个测试查询，每查询最多抽 4 个正确轨迹状态。分别 830 和 877 个候选预测位置。
- 另加 N100 全部 256 个查询的第一条记录，无先前 CoT 内容，避免历史显式候选泄露的混淆。
- 指标是下一 token 是否属于合法候选集合；空候选允许 `|`。不是完整候选字段准确率，也不是最终 YES/NO 准确率。多状态结果先按查询平均。
- 非空/空子集分别在有该类状态的查询中平均，因此不应直接把两个子集百分比作等权平均得到总体。
- 所有前缀、batch16、位置和输入图不变。未覆盖复杂 DAG、深窄/宽浅变体或 BFS。

## 1. 独立实现复核

新增 `recheck.py`，替换 `_attend` 的 mask，直接调用原生 `scaled_dot_product_attention`，没有使用原先的 qkv/proj 输出改写 hook。保留因果 mask。逐例同时对比原始 SDPA、显式因果 mask identity、原 hook 的 FP32 identity 和屏蔽结果。

显式 mask 与 `is_causal=True` 有少量 BF16/kernel 数值差异：N100 clean/error 的 argmax 分别 7/877、3/877 不同，最大 logit 差 3.515625/1.75；两种 identity 的总体合法率相同。原 hook 和原生 mask 的候选位置屏蔽结果，argmax 分别 7/877、0/877 不同，合法率约一致。因此不能声称逐 logit 完全一致，但原来的大幅效果已被独立复现。

|干预范围|N16 baseline|N16 错误训练|N100 baseline|N100 错误训练|
|---|---:|---:|---:|---:|
|无干预|99.28%|99.90%|97.88%|99.12%|
|仅候选预测位置，全部层禁读图|98.37%|59.21%|92.71%|63.44%|
|仅历史当前节点位置，全部层禁读图|79.30%|89.65%|72.85%|85.35%|
|前1层，所有非图位置禁读图|68.39%|74.93%|74.15%|84.18%|
|前2层，所有非图位置禁读图|54.33%|78.45%|67.51%|83.40%|
|前5层，所有非图位置禁读图|45.70%|54.10%|51.01%|59.24%|
|全部6层，所有非图位置禁读图|41.93%|53.78%|47.75%|60.32%|
|最后2层，所有非图位置禁读图|63.18%|59.21%|63.83%|63.44%|

“所有非图位置”包括 query 和所有历史 CoT token，而不只是预测位置；图内 token 保留普通因果 attention。不是删除输入 token。全层禁读仍可利用正确历史中的显式内容，因此总体剩余合法率不能解释为不需要图。

## 2. baseline 关注哪些 token

在 N100 候选预测位置，baseline 对 CoT 的注意力并不分散：

|层|最大单个 CoT key 质量|最大3个 CoT key 质量|CoT 当前节点所有出现位置总质量|
|---|---:|---:|---:|
|4|74.8%|87.2%|59.4%|
|6|78.9%|86.8%|55.0%|

这些都是按状态再查询平均；并非每例都关注同一个位置。一个记录的示例中，L4 给当前 visited 中的 `<V1>` 82.5%，L6 给前一条 PUSH 参数 `<V1>` 77.0%。不应据此把分隔符、其他节点或图内 EDGE 位置忽略；它们也可能承载上下文信息。

注意力集中本身不证明 value 编码了邻接关系，因此继续做下述恢复实验。

## 3. 恢复历史隐藏状态

`rescue.py` 先在未屏蔽的同一输入上保存当前小批次 block residual；屏蔽前 k 层所有非图位置读图后，在第 k 层末恢复指定历史位置的干净 residual。当前预测位置不在恢复集合中。恢复后继续剩余层。activation 只在内存中保留当前小批次。

恢复“当前节点”指 query/历史中等于当前节点 ID 的所有位置。控制组为数量相同、距离最近的其他历史位置；这些控制位置也可能有功能。N100 匹配位置 token 计数为其他节点 8554、`|` 1668、PUSH 728、QUERY 149、`;` 642，并非无信息随机位置。

N100 **非空候选**子集：

|模型 / 屏蔽前5层|无干预|屏蔽后|恢复历史当前节点|恢复匹配历史位置|
|---|---:|---:|---:|---:|
|baseline|95.60%|35.71%|59.11%|35.71%|
|错误训练|97.90%|29.48%|29.71%|29.63%|

baseline 的当前节点 residual 中确有可恢复的功能信息；错误训练模型在这个位置/层的相同恢复几乎无效，与其候选位置直接读图的依赖相符。恢复不完全意味着还存在其他位置/层的贡献，不能视为完整路径隔离。

必须保留的出乎意料结果：屏蔽**第一层**时，baseline 的总体合法率从 97.88% 降至 74.15%；恢复当前节点只到 74.97%，而恢复匹配位置可到 96.03%。因此不能说 baseline 只靠当前节点单一中转，早层其他位置的重要性很高。前2层屏蔽时则为 67.51%→当前节点73.80%，匹配68.20%。

恢复对照检查：无屏蔽时贴回同一当前节点 residual，以及前2层屏蔽后恢复全部非图 residual，两模型最终 logits 都与各自 explicit-mask identity **完全一致（最大差0）**。恢复操作和位置索引通过此正/空对照。

## 4. 没有先前轨迹的第一条记录

所有256个 N100 查询，各取第一条记录，不依赖之前抽样是否选中了它。下表仅非空候选：

|模型|无干预|前1层所有非图位置禁读图|前2层禁读图|全部6层禁读图|
|---|---:|---:|---:|---:|
|baseline|96.40%|13.06%|0.00%|0.00%|
|错误训练|96.85%|70.72%|77.48%|0.00%|

这是 baseline 对早层图信息依赖的强证据。第一层与前两层效果不单调，尤其错误训练模型如此；扩大干预也会改变后续计算状态，不能将每个百分比当作独立可加的层贡献。0% 不是容量结论或理论随机猜测水平，也不等于最终答案准确率0%。

## 解释边界

更准确的描述是：baseline 在早层及历史位置读图，随后候选位置集中读取这些上下文化表示；错误训练模型更依赖候选预测位置第5层的相关边读取。baseline 同时也有后层图依赖，真实通路是分布式的，非纯粹“先读一次再不读图”。

这些结果证实了局部通路依赖差异。未识别 residual/value 的具体邻接编码，未穷尽所有传递位置；attention 和恢复实验尚不能独立排除初始化、训练样本重采样等因素对模型差异的贡献。

原始汇总：`recheck.json`（包含配对查询 bootstrap 区间、集中度和少数 top-key 示例）；`rescue.json`（恢复实验与第一条记录分组结果）。没有存储全 attention 或全 activation。
