# In Context DFS-state：长CoT的行为与attention规律

字段终止已增加专项复查：[FIELD_TERMINATION.md](FIELD_TERMINATION.md)。包含18条test路线与其中6条长查询的局部干预；下文主统计的52条查询分母不变。

**结论：该模型把可见符号和重复节点同时用作上下文相关载体；首先应按行为分组，而不是按字面token追单条亮线。**

本轮冻结同一185k课程模型：52条完整参考轨迹（N16 16条、N100 36条），7255个按行为对齐的事件；N100最长3608个输入token、89条状态记录。另生成12条不按表现筛选的原生轨迹，答案正确9/12，完整严格合法2/12。

主统计是teacher-forced完整参考轨迹，不能解释成全部自由生成正确。自由生成统计仅使用首次语义错误前的完整合法记录；所有失败保留。独立val用于选择传统route的展示层，test用于报告；新发现的root-register解释与局部干预明确标为探索性。

模型：`outputs/scale_v1/launches/scale_v1_s0/context/curriculum/dfs_state/checkpoints/best.pt`，step185000，SHA256见plan.json。CPU FP32；未训练、未占用GPU。

## 实验契约

- N100按label×完整参考长度（≤1024、1025–2048、2049–4096）分层，各cell每split取3条；N16按label×记录数（≤7、>7）各取2条。选择只看标签和长度，不看模型成绩。超出4096的参考轨迹显式排除，不截断后冒充完整轨迹。
- 每query每phase最多12个均匀分布的机会，先query内平均，再跨query平均；95%区间为600次query bootstrap，不把同一长CoT中的token当成独立样本。
- receiver q消费token q、预测q+1；action在第三个bar的行分析，PUSH参数在PUSH行分析，字段结束在新bar之前分析。
- adjacent-layer的2/3跳attention乘积仅是描述性组合，未纳入残差、FFN和Q/K依赖，不作为因果贡献。不同route可重叠，不能相加成分布。
- 语义group把self单列；单独定义的位置route可以包含self，两种统计不混用。低权重交换不是扰动幅度匹配控制，不能仅靠它证明语义特异性；相同可见token、不同上下文value的定向替换结果提供了额外内容证据。
- 传统位置路线已参考并复核项目既有`studies/dfs_pattern_review`；本轮新样本、统计和干预单独保存。

## 1. 字段初始化

**起点不是每次重新从 QUERY 直接搬运：prompt 的 | 是稳定回读位置。**

第一个 stack 节点从 QUERY source 开始。后续 stack 首节点以及 visited 首节点，在 L5 几乎全部回读同一个 prompt 结束符 |。该 | 在 L4 已读取 query source；这是一条可直接观察的两段读取路线。

![模式图](01_init.png)

| 检查项 | N100独立test结果 |
| --- | --- |
| prompt | 读取 QUERY source | L4 70.1%（95%区间 68.8%–71.3%；18查询/18事件） |
| PUSH 后 stack 初始化读 prompt | | L5 99.8%（95%区间 99.7%–99.9%；18查询/188事件） |
| POP 后 stack 初始化读 prompt | | L5 99.8%（95%区间 99.7%–99.9%；17查询/174事件） |
| visited 初始化读 prompt | | L5 99.8%（95%区间 99.7%–99.8%；18查询/199事件） |

6个长查询×stack/visited两种初始化：同样可见字符 | 的 value 交换，12/12 改变预测；sham与低权重位置交换为0/12。

适用范围：“寄存器”是功能性描述：这里证明此局部 value 读取会影响初始化，不等于整段网络只沿这一条路线工作。

## 2. stack 续写

**新栈顶与 POP 后保留的栈节点，应分开看。**

PUSH 后的新内容会读上次动作/参数；POP 后恢复保留栈节点时，L5 强读历史 first-visited 位置。这些位置的可见字母常是起点 s，但其上下文表示与历史栈的父节点有关。按“同名节点”追踪会漏掉这类载体。

![模式图](02_stack.png)

| 检查项 | N100独立test结果 |
| --- | --- |
| POP 后：匹配父节点关系的 first-visited 载体 | L5 94.4%（95%区间 92.0%–96.4%；16查询/74事件） |
| PUSH 后：上次 PUSH 参数（所有续写位置） | L1 59.9%（95%区间 49.8%–70.6%；18查询/125事件） |

此恢复路线本轮以 attention 统计为主；没有把平均读取质量直接解释成栈操作的完整因果回路。

适用范围：这里的94.4%仅指POP后保留节点的条件事件；不能用于所有stack续写，也不等于每个位置都在复制同一字母。

## 3. visited 续写

**可见的 s 也可以成为“新发现节点”的信息载体。**

PUSH(v) 后，下一条记录的 stack 首节点仍写 s，但 L1 对前一 PUSH 参数 v 的平均读取达98.4%。visited 后续续写时，L5 约80.3%注意力落在历史 stack；top-5中有77.2%落在历史 stack-root s 上。它们并非都携带相同信息。

![模式图](03_visited.png)

| 检查项 | N100独立test结果 |
| --- | --- |
| visited续写读取历史stack | L5 80.3%（95%区间 74.5%–85.1%；18查询/200事件） |
| visited续写直接读历史同名visited | L6 21.4%（95%区间 16.1%–27.3%；18查询/200事件） |

六个长查询的中段visited续写：替换“最近发现节点=待输出节点”的历史root value，6/6 改变预测；全部变为donor携带的起点。低权重同字母root和sham为0/6。

适用范围：历史root的“最近发现节点”解释由本轮数据探索得到；其top-5匹配下界为52.4%，不是所有历史root都已解释。L1到L4的残差/FFN混合尚未拆成唯一通路。

## 4. 候选生成

**首次展开从输入图取信息；回溯重访转向历史动作。**

首次处理节点时，L5 读取该节点出边destination后移3个位置的载体；这些位置的字面token可能是下一条边的另一个节点。回溯后再处理同一节点时，L5转而读取它以前的PUSH和参数。不是每次都执行同一种“查邻接表”。

![模式图](04_candidate.png)

| 检查项 | N100独立test结果 |
| --- | --- |
| 根节点候选：相关出边destination+3 | L5 74.9%（95%区间 71.5%–78.4%；18查询/18事件） |
| fresh候选：相关出边destination+3 | L5 73.4%（95%区间 72.3%–74.6%；17查询/167事件） |
| revisit候选：同一当前节点的旧PUSH/参数 | L5 90.6%（95%区间 88.5%–92.5%；16查询/134事件） |

本轮没有把出边+3的高attention当成“图知识已被复制”的因果证明。此前核查显示L1的+3读取本身有很强的格式/距离成分。

适用范围：候选合法顺序不唯一；下一token与canonical参考不同不必然是语义错误。fresh与revisit、空与非空列表均单独统计。

## 5. 字段结束

**visited 已定位到 L5 后继检索；三个字段的停止控制不同。**

复查18条N100 test，其中6条长轨迹做匹配干预。visited在相同可见节点处交换L5 attention输出，停止/节点双向切换12/12；向应结束的位置接入后继root的K/V，5/6输出所接入后继。stack对当前节点身份不敏感，更符合目标长度/阶段边界控制，但计数器未解码。候选L3交换7/12切换到合法类别，另1次变为非法PUSH，未计成功。

![模式图](05_ending.png)

| 检查项 | N100独立test结果 |
| --- | --- |
| visited结束：读取本轮visited | L1 82.8%（95%区间 71.2%–90.7%；18查询/199事件） |
| 候选结束：读visited结束符 | L3 54.9%（95%区间 50.6%–58.8%；18查询/190事件） |
| 候选结束：读visited结束符 | L6 55.9%（95%区间 49.3%–63.5%；18查询/190事件） |
| stack结束：读取本轮stack | L6 67.7%（95%区间 59.0%–75.1%；18查询/199事件） |

新增432个局部输出交换条件、36个单节点编辑、54个长度/全字段身份探针和6个后继接入案例；均为已有6条long查询上的条件，不是新增查询。图中只把节点与分隔符的正确类别切换计入。

适用范围：L3读取候选visited-bar达88.2%，但同字符、更多候选的旧bar-value交换0/6改变停止，不能画成已证实的候选计数器。最后FFN可改变类别也不等于它独立完成停止判断。细节和反例见下方“字段终止复查”。

## 6. action 与选分支

**决定动作与选择 PUSH 的节点，是两个不同的预测事件。**

action由第三个 | 的行预测；PUSH参数由已经消费PUSH的行预测。前者L4强读当前stack，后者L1强读候选。长栈上的FOUND并不总是直读字面栈顶：L4平均89.8%读stack，但仅约0.9%落在真实栈顶token。

![模式图](06_action.png)

| 检查项 | N100独立test结果 |
| --- | --- |
| 预测POP：当前stack | L4 83.6%（95%区间 81.9%–85.3%；17查询/174事件） |
| 预测FOUND：当前stack | L4 89.8%（95%区间 85.8%–93.4%；9查询/9事件） |
| 预测FOUND：字面stack top | L4 0.9%（95%区间 0.4%–1.5%；9查询/9事件） |
| PUSH参数：实际参考选中的候选 | L1 84.3%（95%区间 79.8%–88.4%；18查询/188事件） |

不能再用四节点例子中“FOUND只看栈顶”的路线代表长CoT。动作优先级的完整比较计算仍未定位，已有证据是读取位置的稳定差异。

适用范围：PUSH参数的参考选中候选不一定是自由生成时相同的候选顺序；判断动作与参数的receiver必须严格错开一位。

## 7. 最终 YES / NO

**关键的末尾决策通路在 L1，而不是最亮的 L5 self-attention。**

最终分号 ; 的L1直接读取终止动作FOUND/EXHAUST。只替换这条局部value贡献、保持该层Q/K和attention权重不变，18/18次使最终答案跟随替换后的终止动作翻转。

![模式图](07_answer.png)

| 检查项 | N100独立test结果 |
| --- | --- |
| YES前最终分号：读FOUND | L1 62.8%（95%区间 52.1%–73.6%；9查询/9事件） |
| NO前最终分号：读EXHAUST | L1 57.1%（95%区间 47.7%–67.9%；9查询/9事件） |
| YES前L5：self-attention | L5 99.3%（95%区间 98.5%–99.8%；9查询/9事件） |

反例：L5 self平均99.3%，但把该value换成前一记录同字面分号，6/6仍输出YES。高attention并不自动等于决定答案的语义通路。

适用范围：FOUND/EXHAUST替换是故意不一致的终止前缀诊断，不是另一条合法DFS轨迹；它说明动作到答案的局部读取有作用，不证明此前搜索过程正确。

## 符号与节点载体的分工

| 位置 | 当前证据 | 不能据此声称 |
| --- | --- |
| prompt结束 `|` | L4读source；L5在字段初始化回读；局部value交换12/12改变首节点 | 唯一source通路，或每层都只处理source |
| 每记录stack-root `s` | PUSH后L1读新参数98.4%；visited续写L5回读历史root；探索性交换6/6改变下一节点 | 字面`s`意味着只携带起点；所有中间层已逐段解释 |
| first-visited `s` | POP后保留栈节点L5读匹配父关系载体94.4% | 与stack-root是同一种寄存器，或同一token身份即同一信息 |
| 历史分号 `;` | 多类续写在L2/L4强回读，作为记录级摘要位置很稳定 | 已证明它保存了一个确定的stack/visited全集 |
| 最终分号 `;` | L1动作value交换18/18使答案跟随终止动作；L5self交换0/6改变YES | 最亮L5self就是决策路径；答案正确即可保证轨迹正确 |

## 本轮尚未解决

1. 字段结束已补做局部干预：visited支持L5后继检索，stack更符合长度/阶段边界控制；候选完整耗尽判据与显式计数器仍未拆解，见FIELD_TERMINATION.md。
2. 长栈上的action比较：L4读stack很稳定，但不等于直接读取真实栈顶；跨token状态整合和目标比较的完整回路仍不明。
3. root-register从L1到L4如何经残差、FFN和其他attention保持/重编码：已有读写与局部干预证据，不能画成中间内容完全不变的直线。
4. “模型只有一条符合人类DFS的数据流”没有得到证明；有多个条件路线与分布依赖。
