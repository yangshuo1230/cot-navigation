# “答案改善伴随图检索/候选构造改善”的证据复核

结论：作为所测 checkpoint 的局部行为描述合理；作为整个搜索过程的泛化结论需要收窄；作为答案提升的因果解释尚未验证。

建议表述：在相同 N100 图及正确搜索前缀下，选取的双路 checkpoint 比单路 baseline 更准确地产生出邻居候选集合。该差异与答案表现改善同时出现，但不能据此确定结构改动的独立贡献，也不能确定候选改善介导了多少答案提升。

## 探测实现核对

- 同协议使用相同查询 ID、边顺序、正确历史、frontier、visited；没有把双路模型自己生成的错误历史作为 baseline 输入。
- baseline 与双路均加载 latest/last 权重，分别为 200k 与 140k；统一 eager BF16、batch16。
- 第一条记录不含此前候选集合，DAG 无自环，因此其正确候选就是起点全部出邻居，是较干净的行为性图检索指标。
- 生成第一个候选字段，按集合相等、无重复、闭合判定，不要求与参考顺序一致。所有字段在 24-token 探测上限内闭合。
- 首步非空样本 220 个。第 5 条记录按参考历史是否达到该位置选样，不按模型是否成功选样，因此不存在由模型成功率造成的样本选择差异。
- 该探测提供了正确 frontier/visited，不测量模型自主产生、维护这些状态的能力。

## 配对结果

| 比较 | 首步候选修正 | 首步候选变错 | 样本数 |
| --- | ---: | ---: | ---: |
| DFS baseline → 双路并行因果 | 16 | 1 | 220 |
| DFS baseline → 双路串行因果 | 19 | 0 | 220 |
| BFS baseline → 双路串行双向 | 17 | 3 | 220 |

首步改善不只是不同查询构成造成的均值变化。探索性的配对精确检验 nominal p 分别为 0.000275、0.00000381、0.00258；这些不是跨随机种子的结构效应检验。

第 5 条记录 DFS 并行和串行分别只净修正 5 和 3 个非空候选样本；配对 nominal p=0.0625、0.25。不能将此处的小差异当作稳定的深层搜索改善。

## 第 5 条记录包含历史复用

如果此前已处理过同一当前节点，正确历史可能已打印它的候选列表。此处可能测量复制/过滤，而非重新从边列表提取邻居。拆分后：

| 协议/模型 | 此前未处理该节点 | 此前已处理该节点 |
| --- | ---: | ---: |
| DFS baseline | 111/116，95.69% | 30/30，100% |
| DFS 双路并行因果 | 116/116，100% | 30/30，100% |
| DFS 双路串行因果 | 114/116，98.28% | 30/30，100% |
| BFS baseline | 68/78，87.18% | 74/74，100% |
| BFS 双路串行双向 | 77/78，98.72% | 74/74，100% |

改善集中于首次处理当前节点，支持检索/候选构造的局部行为差异。但首次处理节点也不等于其任何邻接信息都未曾出现在更早历史中，因此仍不构成边列表依赖性的因果证明。

## 答案改善不能直接归因于首步候选改善

DFS baseline → 双路并行因果，相同 256 个主测试查询中，45 个答案从错变对、4 个从对变错，净增 41 个，即 16.02 个百分点。

45 个修正答案中，只有 5 个同时在正确前缀探测中修正首步候选；38 个样本两模型的首步候选原本都正确。因此多数答案修复不能由“首步候选从错变对”单独解释。后续动态检索仍可能改善，但尚未被此实验检验。

答案比较使用历史自由生成记录，而候选探测统一使用正确前缀；两者不是同一套干预。BFS 旧完整主测试缺失，之前的答案提升来自 64 条验证查询，而候选探测来自测试查询，只能描述模型层面的共同变化，不能构成配对的答案—候选因果链。

## 剩余限制

训练总步数、阶段分配、学习率日程不匹配，且每个条件只有一个训练种子；双路探测对象又是根据既有结果选取的表现较好设置。此结论不能推广到所有双路结构，也不能证明结构改动单独造成提升。

下一步关键证据是相同图/正确历史下对真实边做最小反事实修改，检查候选是否跟随改变；以及在 baseline 自由生成中仅修正 candidates，测量能恢复多少答案，并单独记录其他状态错误。匹配训练设置的 baseline 仍是结构归因的必要对照。

原始复核计数见 `baseline_candidate_audit.json`。
