# 六层 base：字段继续／停止的因果定位

冻结原始 step185000 checkpoint，SHA256 `eda85e4deb717c71166d49b6c3f4f1c760fcd3965ed2e9b07eb33a69887e7613`。本轮只研究这个模型，未使用九层纠错模型。

**18 条已有 N100 test query，87 组停止／继续配对、174 个接收位置、15660 次独立条件运行。条件数不是独立 query 数。**

## 结论

**没有一个层统一控制所有字段。visited 的 L5 attention、非空候选末尾的 L3 attention、深栈结束的 L6 attention，呈现不同的因果依赖。stack 在只输出起点与深栈末尾也有不同路线。L6 FFN 普遍携带最终停止／节点输出信息，但这不等于停止算法都在 L6 FFN 中计算。**

## 实验怎样区分影响与控制

- 消融：只把当前接收位置某层的 attention 或 FFN 输出置零，重算本层剩余计算与后续层，观察原有边界是否被破坏。也做等范数随机扰动。
- 双向交换：同一 query、同一可见接收 token、同一字段，一个应输出 `|`、另一个应继续。只交换某一个组件输出，观察停止→节点、节点→停止两个方向。
- 另交换整层残差，并测试半量／反向供体差；全部结果保留。接近输出头的交换有天然优势，只能说明表示足以改变读出，不能自动定位算法。
- 只改当前接收位置、只选一层；历史位置不变。后续层重新计算，不继续覆盖后续层。供体可以来自同条轨迹更晚的记录，这是离线反事实，不是生成时可以读取未来。
- 每个自然供体差配一个同范数随机方向；一个随机方向不是完整随机分布，只是局部对照。未做多重比较显著性宣称。
- 分类严格分 `|`、节点、非法 token；非法 token 不算成功续写。另检查节点是否属于供体场景应输出的内容，以及原始内容是否仍合法。

## 怎么解释各字段

**visited：L5 attention 是最清楚的内容与边界联合接口。** 双向交换 34/36，随机 2/36；成功切换均恢复合法供体内容。其他层的 attention 交换远弱于 L5。和此前后继载体接入的5/6结果相容，支持 L5 的发现序列后继检索参与决定继续或停止。L2–L4 消融也会破坏部分行为，因此不是只有L5有用。

**非空候选的末尾：L3 attention 具有更直接的边界控制证据。** 双向交换 24/34，随机 1/34；严格内容正确子集为 23/28，其中 23/28 符合供体合法内容。这不能解释成候选节点主要由L3检索：L5仍有内容读取作用，L5交换偏向停止→节点，两个方向不对称。

**深栈结束：L6 attention 对维持停止很重要。** 置零后停止→节点 16/17；等范数随机 0/17。供体交换停止→节点 15/17，但这些节点并不等于供体正确下一节点，不能称恢复了正确续写。反方向节点→停止仅 2/17。更像参与停止门控，而非独自提供应续写内容。

**stack 起点位置不同。** L6 attention 的置零与供体交换均不改变边界类别；L4 attention 双向交换 22/36，随机 2/36。不能把此前深栈结论推广到只输出起点的边界。

**初始候选为空，不能沿用非空列表末尾的L3解释。** 17组均匹配同一当前栈顶；L3 attention置零和供体交换均为0/34边界切换。L4 attention置零使非空→提前停止 17/17，相同范数随机0/17；L5 attention置零使空→错误节点17/17，这些节点均不符合供体的合法候选；L6 attention双向供体交换 18/34，随机 0/34，成功切换均符合供体内容。这里体现的是L4–L6协作的依赖，不能说L3统一控制候选字段的全部停止。

这些结果说明 L6 FFN 输出已含可操纵的停止／节点信息；但交换最后 FFN 离输出头很近，其高成功率不证明它负责比较长度或计算集合耗尽。必要性置零结果与充分性交换结果需分开看。

## 校验与限制

- 3132 次 sham 的预测均与原模型相同。696 次完整前向 hook 复算，与缓存后缀重算 argmax 全部相同；最大绝对 logit 差 0.000595093。
- 所有接收者的历史 K/V 在干预前后逐字节 SHA256 一致；缓存重算只覆盖当前位置，避免把历史干预混入接收位置实验。
- 使用已有18条参考query，新增干预条件，不是新增自由生成成功率，也不是全新未见研究样本。每个子场景每条query至多一对，不能把上万条件当成上万样本。
- 本轮定位的是可以影响边界的组件与表示，尚未解出精确长度计数、候选耗尽比较或完整跨位置计算回路。此前L2–L6线性长度方向干预无效的结果仍成立。
- 缓存重放利用因果性：改最后位置不会改变此前位置；验证覆盖每个接收者的L3 attention置零／供体／随机，以及L6 FFN供体条件。其余条件有逐层sham检查。
