# 训练 loss 与收敛检查（2026-10-24）

结论：三个主要落后结构的训练拟合确实更差，仍存在缓慢优化的空间；但现有数据不能把效果差主要归因于步数不足，也不能宣称已经充分收敛。

## 统一口径

baseline 训练 200k 步，课程为 50k/50k/50k/50k；双路训练 140k 步，课程为 40k/30k/30k/40k。批量、模型参数量及峰值/最低学习率相同。最后阶段均为 N100 主导的混合分布。比较按日志 step 保留最后一次记录、统一 100 步网格、1k 步均值，避免恢复训练的重复记录与日志频率影响。

训练 total_loss 是 answer CE 与按样本平均的 trace CE 的和。最终 answer CE 接近零，因此本表主要体现正确历史下的 trace 拟合；这不代表自由生成的查询答案已经学会。原验证日志没有完整 held-out trace NLL 曲线。

## 为什么不能仅解释为未收敛

1. 同样 140k 预算，有的双路结构已经显著优于 baseline；较差结构的尾部下降幅度没有明显异常。
2. 更低训练 loss 也不保证泛化更好：N144 上 DFS 串行因果合法率 22.27% < baseline 30.08%；BFS 并行因果 9.38% < baseline 21.09%。
3. 中途小样本验证有后端混杂：DFS 并行双向 130k 的编译回退计数为 1，140k 为 0；若据此把准确率上升直接解释为学习进步并不可靠。两个较差 BFS 结构也存在早期回退。
4. 当前没有同一结构延长训练后的配对结果，也没有全程固定样本 trace NLL，不能确定优化尚未完成还是接近结构自身的拟合平台。

最直接的区分实验：对较差三组与一组强结构对照，固定最终课程分布，续训 20k–40k，统一解码后端，同时追踪固定验证集 trace/候选 NLL 与自由生成准确率、完整合法率。若训练 loss 降低而后两者不升，就不支持单纯步数不足；若同步追平，则支持训练不足。续训需明确学习率：当前调度器恢复原 max_steps，直接增大训练步数会保持原学习率下限，不会自动重启余弦。此轮未启动续训。
