# 图可达性中的 CoT：首期研究方案

> 2026-10-14 更新：具体实施与计分以 [EXPERIMENT_SPEC_V1.md](EXPERIMENT_SPEC_V1.md) 为准。根据用户澄清，最终可达性答案是主指标，中间轨迹错误不使正确答案失分；预算耗尽仍输出 YES/NO。首批采用 N=200 的三种形状及约 1.23M 模型。下文较早的运行数量和严格轨迹成功标准保留为备选诊断，不作为主实验要求。

日期：2026-10-14。资源：8 张 A800 80GB。范围：从零训练自回归 Transformer；不引入 RL。本文是研究设计，尚未实现训练代码或运行实验。数值均为建议起点，不是实测结论。

## 1. 将项目收敛为可检验的问题

建议主问题：在固定参数规模下，显式推理序列如何改变图可达性任务的可学习性、组合泛化和推理成本？收益分别来自中间监督、额外自回归计算、显式状态维护，还是参数知识的重复调用？

区分三个层次：

1. 行为：同样的模型规模，CoT 能否解决直接回答解决不了的问题？
2. 因果机制：哪些中间状态和模型组件对收益必要？
3. 学习动力学：这些状态和组件在训练的何时形成，是否先学局部转移，再学目标导向决策和搜索状态维护？

“CoT 提取已有能力”是待检验的解释，不能由分别训练的两个模型的准确率差直接推出。分别训练可能产生不同的知识和算法。本文将跨模型比较与同权重、冻结后的推理干预分开。

共享 FFN 为第二条研究线：跨层共享知识存储能否改善隐式组合泛化？先不引入 CoT；得到清晰结果后，才研究两者是否互补或部分替代。

## 3. 必须提前明确的任务边界

### 3.1 图在上下文中，和图在参数中

设图为 G=(V,E)，查询为 (s,t)，目标是 y=1[t 可从 s 经有向边到达]。首期排除 s=t，避免零步路径约定干扰。

**Context-Graph：每例新图。** 训练、验证、测试使用独立图，每例输入节点清单、完整边列表、起点、目标；节点 ID 随机置换，边列表打乱。更准确的名称是基于上下文的图推理，不必将它严格称作 few-shot ICL，因为没有必须从 exemplars 推断的新任务规则。

**Parametric-Graph：固定图。** 每个独立实验世界只有一张固定 DAG；图知识通过训练语料进入参数。评估只输入起点和目标，不再提供边列表。它检验对已学图的组合使用，不检验未见图上的算法迁移。必须在多张独立固定图上重复实验。

两者不要求“相同输入长度”才有比较意义；应比较各自内部的 CoT 增量，再分析差异，不能将两种设置的绝对准确率直接解释为单一因素的因果效应。

### 3.2 “不额外增加 token”的两种含义

路径式 CoT 可以不增加专用词表符号，只输出已有节点 token；但输出路径必然比直接输出 YES/NO 增加序列位置、解码步骤和 KV cache。需要分别报告新增词表大小与新增生成 token 数。

### 3.3 可达与不可达的证据不对称

一条有效 s→t 路径足以证明可达；一条未到达 t 的路径不能证明不可达。

因此定义 Path 为“正例输出见证路径，负例输出 NONE，然后输出答案”。该协议可以训练，但负例没有逐步证明过程，而且 NONE/路径格式本身已泄露答案。最终 YES/NO 准确率不能单独证明逐步搜索能力。

DFS 协议在正负例上均监督真实搜索过程：找到 t 则停止；栈耗尽且已探索所有可达节点则可返回 NO。根据用户最新要求，预算耗尽时中断轨迹并要求模型输出 YES/NO，按实际答案计分；不能将预算耗尽自动记作 NO。训练中也覆盖正确轨迹前缀后给出真实答案的情形。

后续可增加负例证书 S：s∈S、t∉S，且对每条边 u→v，u∈S 蕴含 v∈S。满足这些条件才能据此证明不可达。首期不为 Path 额外引入完整证书，以免同时改变太多因素。

### 3.4 随机游走语料的能力边界

只有随机游走训练、从未出现 YES/NO 的模型，没有学过可达性输出接口。直接询问是否可达的零样本失败，混合了图知识、推理能力和接口学习三个问题。

而且有限正向游走未观察到一条边，并不能证明它不存在。固定图实验需要明确完整性：固定封闭世界语义、节点全集已知、每条真实边在基础语料中保证覆盖，并审计出边覆盖。

采用两个协议：

- **K0，纯随机游走诊断：** 不训练二分类接口；评估局部转移预测、结构表征和路径生成，不与监督可达性模型作等价比较。
- **K1，主要比较：** 共同图知识语料 + 有正负例的任务语料，以 next-token prediction 从零训练。可采用固定比例混合；也可先共同训练图知识、复制同一 checkpoint 后继续训练不同输出协议。后一种属于受控的分阶段语言建模训练，在报告中如实写明，不能称成“仅靠随机游走自然学会二分类”。

所有方法都在预训练阶段获得各自协议监督，不涉及 RL。首期建议 K1 混合训练为主，分阶段训练作为追踪知识复用的诊断。

## 4. 输出协议与核心对照

| 编号 | 方法 | 输出 | 主要用途 |
| --- | --- | --- | --- |
| D | Direct | YES / NO | 直接回答基线 |
| P | Path | 节点路径或 NONE，再输出答案 | 测试路径见证监督和分步调用 |
| S | DFS-State | 候选、访问集合、栈、动作，再输出答案 | 测试显式搜索状态维护 |
| F | Filler | 生成固定数量 WAIT，再输出答案 | 控制额外自回归步骤及位置资源 |

F 在训练时提供固定数量 WAIT/DOT，再监督答案，尝试学习利用额外位置的隐状态。对标准确定性 causal Transformer，在相同 token、位置和 mask 下，逐个输入固定符号与一次 causal prefill 应等价，逐个生成不是必要条件。额外位置不等价于同样数量的实例相关顺序推理步骤；其是否能有效利用需要实验，具体 F0/F1 协议见新规格。

统一输入示例：

```text
NODES a b c d e z
EDGES a b ; a c ; b d ; c e ; e z
QUERY a z MODE DFS
```

一种可验证的完整状态表示：

```text
CUR a STACK [a] VIS [a] CAND [b c] ACT PUSH b
CUR b STACK [a b] VIS [a b] CAND [d] ACT PUSH d
CUR d STACK [a b d] VIS [a b d] CAND [] ACT POP
CUR b STACK [a b] VIS [a b d] CAND [] ACT POP
CUR a STACK [a] VIS [a b d] CAND [c] ACT PUSH c
...
CUR z ... ACT FOUND ANSWER YES
```

严格定义：CAND 是当前节点所有未访问出邻居；按输入边首次出现顺序排序。VIS 采用首次访问顺序，保证序列监督唯一；栈保留搜索祖先。每次到达新节点立即加入 VIS；空候选时弹栈；栈耗尽时 NO。DAG 中也保留 VIS，因为多条支路可能汇合，避免重复探索。

首期 S 输出整个状态，便于检查。第二步增加 **DFS-Action**，只输出 PUSH/POP/FOUND 等动作及必要节点。它与 DFS-State 用同一搜索顺序，从而区分“DFS 算法”与“显式状态冗余”的影响。完整状态快照可能使序列长度接近二次增长，不能根据 DFS 的 O(|V|+|E|) 访问复杂度宣称它的 token 成本也是线性的。

主评估不使用外部 DFS、oracle 候选列表、语义约束解码或自动修复状态。工具生成监督轨迹不等于推理时由工具提供状态。语法约束和外部校验只作为后续独立设置，明确标注。

路径监督优先用与 DFS 相同候选次序下找到的第一条成功路径，减少搜索策略差异。不要默认要求最短路径；最短路径会额外引入最优化任务。任意合法路径在行为评估中均算成功，不以单一参考路径的 exact match 为主指标。

## 5. 图分布、难度与防捷径

### 5.1 分布设计

先使用两种结构：

1. 有可控死路的分层 DAG：控制层数、宽度、分支和汇合，让路径长度与搜索量可以分离。
2. 成对反事实 DAG：在候选图上切换一条关键边，使同一 (s,t) 的答案翻转；用无关区域的补偿改边尽量匹配边数与简单统计，并检查标签相关性。

普通随机 DAG 仅作为参照，不作为唯一训练分布。高密度随机图容易出现短路，长最短路径并不自动代表需要深度规划。

节点标签与拓扑顺序独立；每例重新置换 ID；边列表独立打乱。显式列出孤立节点。固定图中节点身份应保持稳定以允许参数记忆，但初始编号必须随机；评估时不能任意重命名节点后还要求模型保留固定图知识。

### 5.2 正负例

正负例约 1:1。负例不能主要由“目标编号较小”“目标层在起点之前”“孤立目标”组成。优先选拓扑上位于起点之后、有相近层差和度数、却实际不可达的困难负例。

按相近的图规模、边数、层差、起终点度数和可达区域大小配对或分桶。反事实成对图放入同一 split；不让几乎相同的图横跨训练和测试。对度数、边数、ID、首尾边位置等简单特征拟合弱基线，若显著高于随机，需要重新检查数据。

### 5.3 难度变量

每例保存：节点数 N、边数 M、正例最短距离 d、分支数、汇合数、死路规模、参考 DFS 展开节点数 X、最大栈深度 H、累计回溯次数和最大回溯距离 B。对负例不伪造 d，使用 X/H/B 和层差等指标。

X、H、B 依赖邻居次序，是指定算法的难度代理，不是问题的固有计算下界。重要测试例可对多种邻居顺序重复，报告难度分布。不要将 |E|、d、lookahead、DFS 轨迹长度混用。

### 5.4 数据划分

**新图：** 按 graph instance 分割；图重标号或换边顺序的副本必须留在同一 split。单独提供同图新序列化测试，以检查置换敏感性。首期不要求所有测试图与训练图拓扑非同构；若宣称结构泛化，应增加去同构或 motif holdout。

**固定图：** 划分查询对 Q_train/Q_val/Q_test。测试查询答案不进入训练。若希望检验路径拼接，随机游走和 CoT 轨迹不能把测试正查询的完整路径作为连续子串直接展示；对 walk 的所有有序节点子对做审计，不只检查两个端点。

基础一跳事实允许共同训练并审计覆盖；主要 held-out 正查询选择至少两跳。过滤后若破坏边覆盖，补充单边语料。训练 CoT 路径及 DFS 轨迹中也要审计测试查询的完整见证；搜索轨迹的语义泄漏比单纯子串更复杂，因此分别报告“查询未见”和“完整见证未见”，不宣称测试答案在信息论意义上不可推导——它本来就应能由基础边推导。

对固定图至少使用多张独立图，每张图都单独训练自己的模型。图间差异和训练 seed 差异分别统计。

## 6. 模型、训练目标和成本公平性

### 6.1 主模型

使用简单 decoder-only Transformer，固定 tokenization、位置编码、归一化和优化器。单节点单 token，协议符号固定；词表预留到计划的最大节点数，并保证核心节点符号在训练中出现，避免把未训练 embedding 当成长图推理失败。

建议基准：6 层、d_model=128、4 heads、GELU FFN 宽 512，约 1.2M 非嵌入块参数。后续只扫描少量明确轴：深度 2/4/6/8；宽度 128/256。d=256、6 层约 4.7M 块参数。实际参数量以代码统计为准。

先保持基准架构稳定，再在 10M–30M 模型上验证关键结论；100M 以上推迟到确认边界后。8 张 GPU 主要用于独立运行，避免一开始为 1M 模型引入分布式训练复杂性。先测吞吐；小模型可能受 CPU 数据生成、kernel launch 或序列长度影响，多卡不保证线性加速。

Context-Graph 首轮 N∈{16,24,32}；OOD N∈{48,64}。训练难度逐层覆盖，正例 d 可从 1–6 起步，后测 7–12；其他难度维度单独扩展。Parametric-Graph 首轮 N=128，后增到 256/512，并保证有足够多合法 held-out 查询。

这些数值需要 pilot 确认可训练性，不能把优化未收敛误称架构能力上限。上下文窗口依据实测状态序列的分位数确定，记录截断；预算不足优先减小图或采用动作轨迹，不悄悄丢弃难例。

### 6.2 训练损失

所有模型从随机初始化训练，主目标为 next-token CE。图知识语料的采样比例、曝光次数和 loss 设置在各输出协议间一致。

对查询输出，单独归一化轨迹与答案：

```text
L_query = mean(CE_answer) + lambda_trace * mean(CE_trace)
```

Direct 没有轨迹项；答案权重一致。先固定 lambda_trace=1，随后仅对关键结果做小范围敏感性分析。同时报告按全部输出 token 平均的标准 LM loss 版本，避免结论只由人为重加权造成。

答案必须位于轨迹之后，防止先泄露标签。只按序列平均 CE 会使长 CoT 的答案 loss 占比下降，需要显式记录。批量和学习率调度使用清晰单位，记录 query 数、有效 token 数、优化步数与计算量。

### 6.3 三种公平性分别回答不同问题

| 对齐条件 | 能回答的问题 | 限制 |
| --- | --- | --- |
| 参数相同、相同底层图和查询曝光 | 相同模型规模下，哪种监督与输出协议更有效？ | CoT 看到了更多标签 token，也使用更多计算 |
| 参数相同、训练有效 token 或训练 FLOPs 相同 | 给定训练预算下，哪种方法更有效率？ | 可见 query 数通常不同；token 相同也不保证 FLOPs 相同 |
| 参数相同、推理 FLOPs 或延迟相近 | CoT 相比其他计算分配方式是否划算？ | 需要单独设计基线，不能将 teacher-forcing 当推理 |

首轮报告相同 query 曝光，再对关键组补等训练 FLOPs。训练和推理成本分开；推理报告图 prefill、decode、KV cache、生成长度和 wall time。Filler 采用预先确定、与单例标签无关的预算或混合预算；不能在测试时按 oracle 轨迹长度分配 WAIT，否则长度本身可能泄露难度或标签。

## 7. 最小实验矩阵与执行顺序

### 阶段 A：数据与协议验证

实现确定性的 reachability oracle、DFS 状态机和轨迹验证器。此处的测试有必要：验证所有标签、每步候选、栈、visited、终止和切分审计。将生成过程的 seed、图、query、协议版本保存成可复现记录。

检查不同标签下的序列格式与长度分布；短负例、NONE 等接口差异保留为明确局限。主评估同时报告正负类结果，不只报总体均值。

### 阶段 B：24 个主运行

```text
2 个知识来源 × 4 个输出协议(D/P/S/F) × 3 个训练 seed = 24 runs
```

固定图先只用一张图作 pilot；该阶段结果不作为跨图稳健性结论。F 的训练预算分布预先设定，测试时扫描多个预算，避免每个预算都新增主运行。S 的完整快照若过长，先将图规模降到可完整容纳，不变更其语义。

建议先完成新图设置的 D/P/S 各一个 pilot，确认答案、轨迹和失误类型；再启动 24 组。8 张卡每卡一个独立运行，动态分配任务；运行时长和 token 预算由吞吐测量决定，不预设未经测量的 GPU 天数。

### 阶段 C：稳健性与关键消融

1. 固定图扩为 5 张图 × 每图 3 seed × 4 协议 = 60 个固定图运行，包括阶段 B 的 12 个；优先补能影响结论的组。
2. Context-Graph 保留至少 3 训练 seed，并用多个独立测试图集合估计不确定性。
3. 关键模型增加 DFS-Action、相同训练 FLOPs、轨迹 loss 权重敏感性，以及深度/宽度各一个扩展。
4. 保存等训练计算量 checkpoint 和行为变化附近的密集 checkpoint。固定有限语料、反复训练的设置可观察 grokking；持续生成新图的训练不能未经检验直接套用“训练集过拟合后 grokking”的定义。

### 阶段 D：先选具体边界，再做机理

优先挑选三类配对样本：P 成功/D 失败；S 成功/P 失败；局部一步正确但完整 S 失败。用它们定位知识调用、规划选择和状态维护的不同瓶颈。

## 8. 评估指标和能力边界

### 8.1 主要指标

- 二分类 balanced accuracy、YES recall、NO recall、答案 NLL。
- 最终答案准确率为主指标；轨迹无效但答案正确仍计正确。另报答案与轨迹同时正确的严格诊断分数，不将其替代主指标。预算耗尽后仍要求答案，只有答案错误或未产生合法答案才计主指标失败。
- Path 的边合法率、到达目标率、第一步选择正确率。首步正确表示其后仍存在到目标的路径；它比路径结束后的 YES 更有规划信息。
- DFS 的候选完整性与准确性、PUSH/POP 正确率、visited 一致性、栈一致性、FOUND/EXHAUST 合法性、首次出错类型与位置。
- teacher-forced 单步准确率与自由 rollout 成功率分别报告。不能以正确前缀下的表现代替闭环能力。
- 每题 token、展开节点数、回溯次数、推理成本；按模型 seed 和固定图实例报告区间。

若每步正确率近似 q，长度 T 的严格成功率可粗略近似 q^T。这只是独立同分布误差的诊断参考，不作为实际误差模型；用它判断失败是否可能主要来自误差累积，并通过真实 rollout 验证。

### 8.2 主图

至少绘制：

1. 准确率随训练 FLOPs 的变化，D/P/S/F 并列。
2. 能力热图：正例距离 d × DFS 展开量 X，分正负类和知识来源。
3. 生成预算 T × 回溯/最大 frontier 的成功率；对 Path 与 DFS 分别测量。
4. 单步正确率与完整轨迹成功率的差距。
5. checkpoint 上局部知识、目标导向选择、状态维护的形成时间。

定义一个可复现的操作性边界：在指定测试分桶中，达到 95% 最终答案准确率的最大难度，并同时展示完整曲线与置信区间。另可对轨迹质量定义独立边界。95% 是预先声明的实用阈值，不代表理论相变。

OOD 分开测：图更大、路径更长、分支更多、回溯更远、候选更多、序列更长、邻居顺序改变、结构 motif 改变。一次改变一个主轴，再补组合变化；不得把位置外推与算法外推混为一谈。

## 9. 机理证据：从可读出到真正被使用

### 9.1 探针

在预先指定的位置和层训练简单 probe，预测当前节点、目标、栈顶、visited 成员关系、候选集合、k-hop reachable set、桥接节点。Context-Graph 的 probe 应按图划分训练/测试，并对节点置换评估；固定图 probe 应留出查询对。否则 probe 可能自己记住图或学习可达性算法。

对比线性 probe、输入直接特征基线和随机标签控制。报告 probe 复杂度与样本量。可读出只说明信息可访问，不证明模型使用了它；在原始边 token 中读出该边尤其不构成多跳机制证据。

### 9.2 因果干预

使用只改变一条关键边的匹配图，或只改变相关搜索状态的有效前缀：

- clean/corrupt activation patching，观察恢复量及目标状态是否随干预改变。
- 分别替换目标、当前节点、候选、visited、栈的表征，检验预测是否符合状态机。
- 同状态、不同历史的 resampling 控制，检验模型依赖当前充分状态还是依赖历史表面模式。
- 对单头、MLP 输出、残差子空间做消融，配对同数量/同范数随机控制；尽量使用在分布内的替换，避免将异常输入损伤解释成算法变量作用。

“错误轨迹使性能下降”本身证据较弱：可能只是分布外文本。更强证据是状态变量的可控替换，导致预期的候选/动作变化，且同状态异文本替换保持功能。

### 9.3 区分显式 token 与隐状态通道

普通自回归中，后续生成可读取历史 token 的 KV，其中包含它们在生成时的上下文化隐状态。可见 token 并非唯一的信息通道。

关键对照：

1. 正常继续解码，保留生成时 KV。
2. 在训练覆盖的格式中，仅保留图/查询和当前完整离散状态，移除旧步骤，重新 prefill 后继续生成；此时不沿用状态 token 原来携带旧历史的 KV。
3. 构造同一当前状态、不同合法历史的样本，比较正常续写与状态重建后的行为；对位置变化提供匹配控制。

2 引入了显式离散状态瓶颈，用来检验当前文本状态是否足以支持续写；它也改变了输入长度和重算成本，因此要单独记账，并使用训练覆盖的状态重启格式。不能通过随机删前缀的下降直接证明“CoT 需要全文历史”。

特别注意：对于标准确定性 causal Transformer，若保留完全相同的整个 token 前缀、位置和 mask，丢弃 KV 再完整 prefill 在数学上应重建相同的隐藏状态（忽略数值误差）。这只能用于实现一致性检查，不能作为切断隐状态通道的实验。必须真正限制历史可用信息，例如上述只从完整离散状态重启。

### 9.4 对“提取已有能力”的更强检验

训练同一个带 MODE 标记的混合协议模型，让它在预训练时见过 DIRECT、PATH、DFS、FILLER。冻结权重后，对完全相同的查询切换协议。先进行这一训练覆盖内的比较，避免测试时强行禁止一个只会 CoT 的模型输出轨迹。

再结合共享基础 checkpoint 的分支实验、局部事实掌握程度、桥接信息读出、激活干预和预算控制。若同一冻结模型在 CoT 模式下稳定组合其已掌握的局部知识，且中间状态干预有预测性因果效应，可以表述为“CoT 改善了该模型已有知识的调用与组合”。依然不能仅凭此证明全部抽象推理算法早已存在。

## 10. 功能集中现象如何操作化

分别定义：

- 计算功能集中：少数头/层/子空间控制局部边检索、候选筛选、回溯或最终判定。
- 图知识集中：特定边或节点事实更依赖少量组件，尤其关注固定图。
- 存储冗余：同一局部事实是否在不同层重复可访问，是否只能在特定跳数位置调用。

方法是画组件消融的准确率下降曲线，做渐进 top-k 与随机 k 对照，必要时补充分组消融及保留组件的恢复实验。所谓“最小子网络”应说明搜索方法和阈值，不能将一次 greedy 结果当全局最小。

跨 seed 比较功能角色和因果模式，不要求同编号神经元对应。单神经元集中度依赖表示基底；MoE 路由集中也可能只是负载不均，不能单独证明语义功能集中。UMAP/PCA/Isomap 只作探索图，配合 held-out 的结构距离、邻接/可达性读出和干预证据。

## 11. 无 CoT 的共享 FFN 实验

先在 Parametric-Graph 上研究，再用 Context-Graph 检查收益是否依赖参数知识。保留逐层独立 attention 和 normalization，只改变 FFN，避免同时引入完整循环网络。

令层数为 L，hidden dimension 为 d，普通 FFN 中间宽度为 m；两层 GELU FFN 忽略 bias 的参数约为 2dm。

| 架构 | FFN 总参数 | 每 token 跨 L 层的 FFN 计算量比例 | 作用 |
| --- | --- | --- | --- |
| A：逐层独立 FFN，宽 m | L·2dm | 1 | 标准基线 |
| B：同宽共享 FFN，宽 m | 2dm | 约 1 | 固定单次调用计算下观察共享的影响，但总参数减少 |
| C：大共享 dense FFN，宽 Lm | 约 L·2dm | 约 L | 固定 FFN 参数量，但计算显著增加 |
| D：跨层共享 expert bank，L 个宽 m 专家，top-1 | 约 L·2dm，加 router | 约 1，加 router | 总参数和激活计算近似对齐，检验跨层复用与条件路由 |

比较 C 与 A 时必须报告额外计算；“参数量相同”不代表公平的计算对照。B 的作用是机制基线，不是完全匹配的性能竞争组。

为了识别 D 的收益：

1. 加 **按层固定 expert 分配**：每层固定用一个不同专家；它在函数形式上接近普通独立 FFN，是共享 bank 的结构控制。
2. 加 **所有层固定同一 expert**：检查纯复用，但其有效使用容量较小。
3. 对比动态 router；先用最简 token-wise shared router，不额外注入层 ID。检查其是否从隐状态中间接按层分工。
4. 报告独立参数、激活参数、实际 FLOPs、延迟、专家利用率、跨层路由重合度与负载均衡设置。

路由高重合不等于知识共享，低重合也不自动等于失败。需要构造“一跳出现、组合角色未见”的边/事实集合，比较它们处在第一跳和后续跳时能否被调用，并做 expert 消融或状态 patching。该测试比普通 IID 准确率更贴近跨层知识复用的主张。

关于新颖性：Wang et al. 已在 Appendix E.2 通过前后层参数共享改善组合任务 OOD。这里的价值应落在 DAG 可达性、受控容量与计算、共享 expert bank 的复用证据上；是否形成论文贡献还需要更完整的后续相关工作检索。

## 12. 结果解释与推进条件

| 观察 | 可支持的解释 | 不能直接推出 |
| --- | --- | --- |
| P/S 优于 D | 对应训练与输出协议在该预算下更有效 | CoT 仅提取了 D 已有的算法 |
| S 优于 P，尤其在回溯难例 | 完整搜索状态表示有帮助 | DFS 对所有图和所有预算都更好 |
| F 接近 S | 额外计算或隐状态通道可能解释相当部分收益 | 离散 CoT 语义完全无用 |
| 单步很准，rollout 差 | 状态漂移与误差积累是候选瓶颈 | 模型完全不具备局部搜索操作 |
| 增加深度改善 D，增加 token 改善 S | 层内计算与序列计算存在可测差异 | 每层/每 token 必然对应一跳 |
| 共享 expert bank 改善组合角色迁移 | 跨层复用或路由是候选机制 | 知识只储存在 FFN 或已证明存储共享 |

首期成功标准：得到一个对多 seed/多图稳健的能力差异或明确的无差异结果；将差异定位到可测难度轴；至少通过一种有预测性的因果干预区分两种机制解释。即使 CoT 没有优势，若能定位失败在候选枚举、回溯还是误差积累，依然构成有用结果。

迁移到通用模型时先验证已识别的具体机制预测，例如同长度不同状态表示、错误候选修复、缓存重建或跨层调用，而不只重跑 YES/NO 准确率。自然语言图描述、分词和既有知识会引入新变量，应逐步加入；小型 DAG 上的发现不自动外推到通用推理。

## 13. 首批实现应交付的材料

1. 可复现的图、查询与轨迹生成器；独立 oracle 与 validator；数据切分和泄漏审计报告。
2. 简单 decoder-only baseline；D/P/S/F 配置；模型参数和训练/推理预算统计。
3. 自由 rollout 评估器；按难度和正负类输出结果；错误轨迹的结构化记录。
4. checkpoint 与模型 seed、图 seed、数据 seed、协议版本的对应清单。
5. 24 组首轮对照结果，再决定扩大图数、模型、DFS 编码和共享 FFN 的顺序。

建议第一优先级：新图设置下 D/P/S 的可训练性与数据防捷径检查；随后补齐 F 和固定图。共享 FFN 在线路清晰后进入，不与第一批 CoT 对照同时叠加。
