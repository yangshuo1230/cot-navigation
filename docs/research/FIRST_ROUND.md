# 首轮小图训练设计

2026-10-15。首轮确认规格，对应项目紧凑协议实现；正式训练尚未启动。本文件优先于旧规格中冲突的首轮设置。

## 确定的实验范围

| 设置 | N | M | 层数×宽度 | 每例图输入 |
| --- | ---: | ---: | --- | --- |
| Context-Graph | 16 | 24 | 4×4 | EDGE u v … QUERY s t \| |
| Parametric-Graph | 32 | 48 | 8×4 | QUERY s t \|，每个世界固定一张图 |

两组均从小图开始。图只含相邻层正向边，恰好 M 条；先使用单一形状。之后再扩图和比较宽浅/窄深，不把小规模下的最大宽深比与最大边数同时推高。

模型保持 6L/1H/d128/FFN512/GELU/RoPE，四种协议独立训练，固定图从共同 walk checkpoint 分支。两种知识设置规模不同，准确率不能直接用于估计知识来源本身的效应；主比较在各自设置内部进行。

特殊词表：PAD、EOS、EDGE、QUERY、|、;、YES、NO、PUSH、POP、FOUND、EXHAUST、WALK、DOT；加 256 个节点 token，共 270。节点在各角色中共享 embedding 行，输入输出权重绑定。

删除 ANS、模式标记、预算 token 和 CUT。所有 DFS 训练轨迹完整，不学习截断后回答。主指标仅最终 YES/NO；轨迹质量单独诊断。

## 四种输出

```text
Direct: YES EOS
Path:   s ... t YES EOS       # 负例 NO EOS
DFS:    stack | visited | candidates | action [node] ; ... YES/NO EOS
Filler: DOT × N YES/NO EOS
```

DFS 的当前节点是栈顶；候选仅为未访问真实出邻居；先到目标则 FOUND，否则优先 PUSH 第一个候选，无候选且有父节点则 POP，否则 EXHAUST。状态在动作前，POP 不删除 visited。图和查询是条件输入，全部搜索字段由模型生成。

Filler 固定长度 K=N，新图16、固定图32，与图、标签和参考 DFS 长度无关；训练提供 DOT，loss 仅答案 CE，测试提供相同固定 DOT 后生成答案。不输入 K，不要求生成次数与 DFS 相同；后续 K=N/2、N、2N 为独立消融。暂不混入显式 CoT 辅助训练。Filler 没收益不能证明所有 filler 训练方式都无效。

WALK 保留为图知识数据类型标记：`WALK u v ... EOS`。只监督转移节点，不监督起点和随机停止的 EOS。覆盖全部基础边，随机游走与目标查询不绑定。

查询仍按层差和标签分层；固定图主要任务 d≥2，查询对 holdout，完整 walk 见证暴露单独审计。正负池不全时先记录条件化影响，不用倒序负例凑数，也不复制查询跨 split。

## 生成器检查，而非训练结果

随机种子确定，每种配置无条件采样 1000 张图；平均比例按图计算。下表正例比例枚举起点在前、层差 d≥2 的所有查询；分支比例仅统计非末层节点。

| 图 | M | 至少两个后继的节点比例 | 前向多跳查询正例比例 |
| --- | ---: | ---: | ---: |
| 16 节点，4×4 | 16 | 41.2% | 37.6% |
| 16 节点，4×4 | 24 | 69.8% | 72.7% |
| 16 节点，4×4 | 32 | 89.8% | 93.5% |
| 32 节点，8×4 | 32 | 32.3% | 24.4% |
| 32 节点，8×4 | 48 | 57.5% | 63.4% |
| 32 节点，8×4 | 64 | 79.2% | 88.0% |

所以 M/N≈1.5 作为起点：增加分支和汇合，避免初期大量短链或无后继节点，同时不采用高度稠密、负例稀缺的图。不是搜索难度单调最优的结论，也不是文献原值。密度消融保持形状不变：新图 M=16/24/32；固定图 M=32/48/64。

另从每张图随机选 d≥2，若该 d 正负池均非空，分别抽一个正负例检查完整 DFS。32 节点 M48 组的输出 token 数 p95=996，样本最大1340；该统计不是严格最大值，也不是最终训练分布的预测。

上下文 4096：按当前四字段紧凑语法，N32/W4/M48 的保守长度界也能容纳（输出≤3508，固定图输入4 token）；N16/W4/M24 新图输入输出合计保守界≤1060。界使用最多2N−1条搜索记录、栈总长度≤N²、visited总长度≤N(2N−1)、候选总长度≤M(W+1)/2。仍需在实现中逐例断言，禁止静默截断。模型自由生成可能不终止，设置统一安全上限，超限按失败记录，不能改成 oracle 答案。

## 固定图两阶段训练（最终确认）

Stage A 仅5k条1–4边随机游走及补充一跳边，全部边至少监督100次；1k updates，walk batch64。知识阶段不加载查询数组，不采样、不训练或验证查询。

Stage B 从共同 Stage A checkpoint 复制四组，2k updates，每步64查询+16 walk；task与walk loss分别归一化后相加。任务输入无图。各组查询和walk次序对齐。新图10k/2k/2k，训练2k updates、batch64，共128k次查询曝光；固定图查询按20%/10%/70%划分、按距离平衡。

四组都有独立入口：configs/experiments/main_context_{direct,path,dfs_state,filler}.yaml 和 main_stage_b_{direct,path,dfs_state,filler}.yaml；知识阶段 main_stage_a.yaml。filler_tokens=null自动取N，不会在输入中增加长度标记。


数据量缩减：固定图5k为随机游走基础条数，边覆盖不足时补充一跳记录，最终条数可能略高；基础边每条至少监督100次。共同warmup调整为100步。固定图查询划分、图规模、四种协议与Filler长度不变。
